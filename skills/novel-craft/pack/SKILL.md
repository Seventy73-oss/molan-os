# 网文选题与创作（novel-craft）

## 〇、数据边界与证据分级（使用前必读）

**数据是什么**：1983 本中文网文样本（本地书库"中文小说大全"合格池全量，六轮递进选样；**书库合格池已全部蒸完**）**开头约 1 万字**的逐本拆解（章节结构、钩子链、冲突条目、架构、爽点、文风七维、金句）。

**数据不是什么**：
- **开局覆盖深、全书覆盖浅**。func 配比/强度/节拍/母模板描述的是"前 1 万字"；全书结构原有部分属推演，现由 `data/长篇结构骨架.md` 补上了第一批全书级证据（1983 本章节/卷骨架统计 + 16 本高分书卷级抽样），但仍非全样本结论。
- **score 1~5 是拆解 agent 的主观综合评分**，不是客观热度/成绩指标，仅用于组内排序与筛高分样本。
- **题材归属来自书库索引**，存在少量错标与同书异名/重复条目（已发现并标注若干，如《六纬神功》实为《鹤高飞》）。统计量受此影响约在个位数本级别。

**证据分级（引用时自觉对号入座）**：
- **A 级｜脚本统计**：题材卡「数据面」的 type/func/强度分布、score 分布。可直接引用，但它是**分布描述，不是达标指标**——偏离均值的书大量存在（如慢热流整族违反"金手指 3 章落地"）。
- **B 级｜多书归纳**：母模板、签名手法、冲突链、loop 公式。使用时以卡内代表书为锚，注意卡内已列的反例与例外条款。
- **C 级｜经验推演**：中期走向、长线动机管理、审查清单的扩展项。标注为推演，允许用户依创作判断取舍。
- **军事题材**：仅 19 本且为旧口径，一切结论标注"小样本、低置信"。

**三条纪律**：
1. 引用统计必须注明来源卡与条目（如"仙侠卡·冲突配方"），不得跨题材外推——跨题材迁移只走总览的「冲突借用指南」并按其改造方法处理。
2. 铁律与题材卡内反例冲突时，**以题材卡为准**（铁律是多数规律，题材卡内已列明哪些流派刻意违反）。
3. 卡内书名、公式、金句不得编造或改写；找不到依据就明说"无数据支撑，属创作判断"。

## 长篇使用姿势（推荐节律）

蒸馏数据只支撑开局 1 万字；长篇主体（卷结构、中后期节奏、防崩坏管理）走 `data/templates/` 模板体系（C 级推演已标注）。节律：

1. **开书**：选题单 → 拷贝模板 → 填建书档案（卷框架表占位，长篇预留 6~9 个大境界）+ 人物表 + 伏笔台账。
2. **每卷**：填卷纲（三幕结构 + func 配比自查 + 升级获得清单）→ 重写前情摘要的"当前卷速览"。
3. **每章**：填章纲（六问 + 钩子四选一 + func 标注）→ 按文风卡写正文 → 对照写作红线自查 → 回写人物表/伏笔台账。
4. **每 5 章**滚动前情摘要；**每 10 章**一致性体检；**每卷末**跑「长程节奏与专项检查」全清单（兑付升级、伏笔存量、势力纵深、人物巡检）。

## 全流程工作流

### 阶段一：选题 →「选题单」〔依据：A+B 级〕

1. 读总览「题材选择速查表」+「跨题材铁律」，定题材；同时看「均值陷阱」提示——score 均值高≠好写，先看该题材 5 分书存量与拥挤度。
2. 读对应题材卡「开局母模板谱系」+「1 万字节拍表」，定开局模板与节奏路线；**核对卡内反例流派**（如仙侠凡人流、玄幻慢热流刻意违反快节奏铁律），确认选的路线与铁律的适配关系。
3. 用「冲突配方」拼 3-5 个冲突点：type 组合参考题材分布（分布是参照系，不是硬指标）；跨题材差异化只走总览「冲突借用指南」并按改造方法处理。
4. 产出**选题单**：细分定位一句话 / 开局母模板+节奏路线 / 冲突链（每条标 type、intensity 1-5、func）/ 金手指+限制代价 / 爽点循环+第一个爽点 / 长线动机与主线悬念 / 文风要点+2-3 本对标书 / 差异化说明（与对标书的具体区别）。

### 阶段二：开书设定 →「建书档案」〔依据：B 级 + 推演〕

- 产出：书名候选×3、一句话卖点、题材定位、世界观与力量体系、**金手指及其限制/代价**（B 级规律：高分书金手指普遍带代价/限制，题材卡金手指库有逐类示例）、人物表（反差设计参考题材卡 hero 归纳）、卷框架、第 1 章细纲。
- 长线动机参考题材卡 arch.goal 的"恨+爱"双绑定归纳（C 级推演，按故事取舍）。
- 悬念管理：主线悬念 1 条贯穿，章末小钩逐级升级，未回收伏笔不提前揭底（B 级，各卡钩子链普遍模式）。
- 目标平台为墨澜工坊时，可按其 `bookSetup` JSON 格式输出一键建书包（files 分组只允许：设定/细纲/正文/参考）。

### 阶段三：细纲〔依据：B 级（前 10 章）+ C 级（其后）〕

- **前 10 章按题材卡节拍表铺**——这是蒸馏数据直接支撑的部分；第 10 章之后的走向属于推演，需自行设计并说明理由。
- 每章过「六问」（墨澜工程实践总结）：章目标一句话 / 场景经济（2-4 场，每场至少做两件事）/ 冲突具体（谁想要什么、被什么拦住、结果）/ 信息差（读者知 vs 主角知）/ 看点落位 / 钩子选型（危机切断/新信息/预期反转/收获停半，不连用同一种）。
- 单章篇幅参考题材卡逐书「约 N 字」分布（多数 2000-3500 字）。

### 阶段四：正文〔依据：B 级（文风卡）+ 墨澜工艺〕

- **动笔前读对应 `data/文风卡-X.md`**：视角纪律、句式节奏模板（按子类型选路线）、对白三功能、用词底色与忌词、签名手法落地步骤、动笔自查清单。
- 通用工艺规则（墨澜写作工程总结）：能「演」不「讲」；对白贴人设带潜台词；中文全角标点；无 AI 腔/翻译腔/总结腔；紧扣细纲不复述前文；句长控制节奏。
- 签名手法是题材辨识度来源，按卡内步骤执行；卡内标注"自拟示例"的模板可仿结构、不可抄内容。

### 阶段五：审查迭代〔依据：B 级对照 + C 级〕

- **一致性红线**（墨澜工程实践，违反即改）：①不新增档案外重要人物/设定；②不提前揭底未回收伏笔；③姓名/身份/伤势/位置与人物表一致；④时间线紧接上一章不复述；⑤已解决冲突不重复解决、已回收伏笔不再用；⑥只写细纲规定节拍。
- **开局诊断**（对照题材卡节拍表逐项打勾）：落差是否立住 / 金手指 3 章内落地且带代价（或所属流派按卡内反例豁免）/ 首个爽点是否规则场当众兑付 / 章末钩逐级升级。
- **爽点节奏体检**：铺垫+悬念约六成为题材健康态（A 级分布参照）；警惕两类低分死法——「多章无兑付」与「兑付后无对抗」（游戏卡 2 分样本实证）。
- 修改产出须注明：改了什么、依据哪张卡哪一条（或明示为创作判断）。
