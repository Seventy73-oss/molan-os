# 开局类型总表（1983 本跨题材分类）

> 数据口径：1983 本全部来自《汇总输入》十张题材卡的 open_type 字段原文——玄幻 446、都市 355、仙侠 239、言情 208、武侠 189、悬疑灵异 157、历史 129、科幻 121、游戏 120、军事 19。
> 归类方法：对每本 open_type 原文按「开局类型标签＋关键词」归入 16 个大类，一书只入一类；复合开局（如"重生＋废柴""穿越＋绝境"）按其 open_type 中排在前面的主导特征归类，故**频次是近似值（±10% 量级），相对排序与题材分布可靠，精确计数不可较真**。所有书例与标签均抄自 open_type 原文。
> 与《跨题材总览》五大母模板的对应：A 受辱-亮牌打脸流 ≈ 废柴觉醒＋身份错位藏拙＋归来下山；B 重生/穿越先知流 ≈ 重生回归＋穿越穿书＋转世还魂；C 死局倒计时/绝境求生流 ≈ 危机绝境＋悬案灵异（案发侧）；D 误会/系统反套路喜剧流 ≈ 系统降临＋轻喜反差；E 慢热悬念/世情铺垫流 ≈ 日常慢热＋悬念倒叙。

**高分倾向开局**：危机绝境、复仇雪耻、使命任务（均分 3.88 且零 2 分）、悬案灵异（5 分绝对数第一）、废柴觉醒（高频且 5 分率 7.0%）。共同点：开局自带死局/仇恨/任务等"不可逆事件"，压力天然分层，兑付有刻度。
**低分倾向开局**：系统降临（1.6% 五分率、2 分最多）、金手指奇遇（零 5 分）、裸穿越无死局变体。共同点：金手指"当章即赢"，无代价无对抗，爽点一次性透支。
**低分死因**（与《低分书失败模式》互证）：①系统类"只堆兑付无人设底色"（低配综漫魔君系统流今天开始当魔君仅 2 分——差的不是题材是布局感）；②奇遇类"金手指当章即无敌，无限制不许出卡"；③穿越类"落地后无死局倒计时，先知变设定说明书"；④所有大类的共同死线是"四章无兑付"。
**高分规律**：5 分从不靠开局类型本身，靠"开局类型×执行力"——玄幻 18 本 5 分里 14 本是慢热/悬念/强概念系；反套路老六流（开局鬼上门）、黑暗反派流（神圣祷文）、体制职业流（我在镇魔司斩妖三十年）是近年验证过的新高发带；言情当前 5 分聚集在战争/冷战宿命双线。

## 五、开局选择决策树

```
你想写什么？
│
├─ 先问两个前置问题
│   ├─ 你能管住多少条伏笔？→ 少（3条以内）选快热型（1/2/4/5/13 号组合）
│   └─ 你能忍多少章不见爽点？→ 忍不了就别选慢热型（9/16 号组合）
│
├─ 想冲 5 分（愿意慢热、能管伏笔）
│   ├─ 能写世情与风俗质感 → 日常慢热铺垫入异常（剑来式）／悬念双谜（牧神记式）
│   ├─ 能立高概念 → 悬案灵异·观念恐怖（三体式）／密室死亡游戏（十日终焉式）
│   ├─ 能写群像与双线 → 倒叙虐点前置（三生三世式）／冷战宿命双线（Bomber's Moon 式）
│   ├─ 能给死局做硬节拍器 → 危机绝境·倒计时（死在火星上、甘十九妹式）
│   └─ 敢写反派/非常人 → 恶人洗白/大反派重来（神圣祷文、功德印式）
│
├─ 想保 4 分基本盘（求稳、走成熟赛道）
│   ├─ 写男频玄幻/仙侠 → 废柴觉醒（受辱-觉醒-规则场打脸）或重生复仇清算
│   ├─ 写都市 → 重生先知（先救亲人/锁仇人）或身份错位藏拙（读者全知豁免）
│   ├─ 写悬疑灵异 → 悬案接案＋民俗行当职业流（一条规矩＋一桩异象）
│   ├─ 写历史 → 穿越死局倒计时改命，或装怂求生官场流（复仇书生式）
│   ├─ 写武侠 → 纨绔藏拙亮牌或灭门遗孤蛰伏复仇（武侠没有重生系传统，勿硬搬）
│   ├─ 写言情 → 穿越/重生壳＋退婚/先婚后爱，冲突主力换生存危机×情感拉扯
│   ├─ 写游戏 → 无限流/死亡副本（任务失败即真死，智斗先于武力）或重生抢跑
│   ├─ 写科幻 → 灾变档案直入（一句宣言一道死线）或硬核设定悬疑（异常须可验证）
│   └─ 写军事 → 危机开场＋惨案幸存立誓（样本小，参考最强兵王）
│
├─ 想做差异化（避开红海）
│   ├─ 大类换题材迁移：只换"压力源＋兑付通道"，骨架不动（五大母模板迁移表）
│   │   例：系统式兑付通道→玄幻体制职业流；倒计时→历史秋决/车裂死线；
│   │        情感泵→护家流开局火引（妻女受辱当火引）；游戏公告打脸→玄幻全民选拔直播
│   ├─ 蓝海但天花板未验证（最高 4 分）：非人转生/进化流、领主/神祇/宗门养成流、
│   │   诸天/两界穿行流、签到囤积复利流、女频玄幻/人外恋流
│   └─ 避雷：金手指奇遇（零 5 分）、裸系统流（1.6% 五分率）、无死局纯穿越
│
└─ 定完大类后的四步自检
    1. 开局四要素齐了吗：身份设定＋触发事件＋金手指亮出方式＋首个冲突（缺一即 3 分开局）
    2. 金手指有限制/代价吗（没有限制的金手指不许出卡——铁律 3）
    3. 第 1 章末挂上首条悬念了吗；四章内有第一次兑付吗
    4. 双动机并联了吗：恨（复仇/雪耻）＋爱（护亲/守护）各一条
    5. 复合叠装对了吗：两组合叠装时基调要能共处（压×紧可叠，压×松需第一章内切换）
```
