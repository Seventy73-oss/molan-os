# 开头技法 · 真人语料全量实证（52本第一章开头）

> 数据源：`04_语料/真人语料_网文57本`，**52 本可解析**（全量，覆盖 100%）。
> 方法：每本取第一章正文前 300 字，提取首句并归类。
> 用途：`提示词零点五·规划表` 的 P01 注记；**首句要求属注记，不进硬规则**（作者指示）。

---

## 一、首句类型分布（52 本实测）

| 类型 | 本数 | 占比 | 例子 |
|---|---|---|---|
| 叙述/其他 | 20 | 38% | `我的名字叫做苏神，小名小添……`／`美利坚。` |
| **对白/引语** | 11 | 21% | `“长生真是寂寞如雪啊。”`／`“我……是谁？”`／`“警报，警报……”` |
| **地点锚** | 8 | 15% | `金港城又被称作天使之城。`／`大原朝，江浙行省，杭州路，钱塘县。` |
| **时间锚** | 5 | 10% | `甲龙历，412年。`／`2000年夏天。`／`2013年6月30日，京都某咖啡馆内。` |
| 感叹/疑问 | 3 | 6% | `吱吱吱！`／`这是一双漂亮的手！`／`‘咚！咚！’` |
| **系统/格式** | 3 | 6% | `【你击杀了滩涂沙虫】`／`【已死之人，欢迎来到维度乐园】`／`【肯辛顿-切尔西区-国王路128号-2楼主卧】` |
| 身体痛感 | 1 | 2% | `浑身剧痛、头疼欲裂、满嘴血腥、肚皮将被撑破……` |
| 环境/天象 | 1 | 2% | `太阳悬在高天，将它的光和热，不偏不倚洒落人间。` |

### 关键结论
> **52 本里，只有 1 本以"某人醒了/穿越了"式起手**（《天弈：棋圣之路》——而且它是「诸葛一再度醒来的时候，」这种**被截断的复合句**，后面还接着内容，不是单句交代）。
>
> 某本自测稿的第一句 `XX是被冻醒的。` —— 属于 **52/52 之外的写法**。
> （⚠️ 2026-09-11：原句含该书主角名，已去名；反例本身通用，任何书的开场都不建议用"某人醒了"式单句。）

## 二、各档首句实例（照档取用）

### 西幻/异世界（9本）
```
吱吱吱！                                    ← 亡灵之息（拟声）
随着钥匙扭动的咔哒声。                        ← 唯我独法（拟声）
文城北郊，一栋自建别墅的地下室之内。            ← 天降魔主（地点）
【你击杀了滩涂沙虫】                          ← 奇诡航海（系统）
甲龙历，412年。                              ← 无职转生（时间）
城都地区，愤怒之湖东北山区。                   ← 精灵世界（地点）
【已死之人，欢迎来到维度乐园】                 ← 维度乐园（系统）
银河系·余烬星环，围绕红巨星旋转的一颗暗黄色固态行星。 ← 进化乐园（天文）
光网上，全星际瞩目的直播频道早已刷满了密密麻麻的弹幕…… ← 第四天灾（场外）
```

### 都市/职业（18本，摘录）
```
我的名字叫做苏神，小名小添，曾经的最快黄种人教授。   ← 自我介绍式
动荡之年，全球经济疲软失业激增。                  ← 时代背景
2013年6月30日，京都某咖啡馆内。                  ← 时间+地点
金港城又被称作天使之城。                        ← 城市外号
“李珞！你这也太过分了！赶紧给班长道歉！”          ← 直接进冲突对白
这是一双漂亮的手！                              ← 特写+感叹
“叮咚，阶段任务：帮助三博医院建立G市最强骨科。”    ← 系统提示
```

### 仙侠/玄幻（13本，摘录）
```

大原朝，江浙行省，杭州路，钱塘县。                ← 行政区划
“长生真是寂寞如雪啊。”                          ← 对白

太阳悬在高天，将它的光和热，不偏不倚洒落人间。      ← 远景宏观
```

## 四、P01 检查表（规划表注记，非硬规则）

- [ ] 首句**不是**"某人+状态/动作"的交代句（`XX冻醒了`／`XX穿越了`／`XX睁开了眼睛`）
- [ ] 首句**不是**主谓宾完整交代句；优先：拟声／时间锚／地点锚／系统格式／对白／外号
- [ ] 前 3 段内出现一个**不属于主角的外部先兆**（声音、警报、火把、弹幕、雨声）
- [ ] 前 300 字内出现**一个具体的异常物件或异常事件**
- [ ] 背景信息**挂在一件道具上**，不靠叙述交代
- [ ] 主角的**第一句台词**很短，且是疑问或自嘲
- [ ] 内心独白不早于第 5 段出现
