## 一、每章 7 步（写和改都交子代理，主会话只跑脚本与协调）

```bash
# ① 主会话：拼注入包（减负后 ≤3,500 字）
python scripts/build_context.py --chapter 第02章 --tables "设定表_书名.xlsx" \
    --genre "西幻/异世界" --terms "术语表_书名.txt" --out "_context/第02章_注入包.md"

# ①-b 主会话【硬性·2026-09-11 新增，不许跳】：打开注入包搜两个告警串，任一命中即停下，不许开写
#     A. "未匹配到题材档靶板" → 改 --genre 到现有 8 档之一，或新建该档
#        （新建档必须同时含「注入指令」节与「最小范本集」节，范本只能取真人语料并标出处）
#     B. "缺「最小范本集」节"  → 该档没有真人原句，先补 2~3 条摘句（带出处）再重跑
#     两个都没有 → 注入包第八节开头应是「最小范本集（真人原句）」，**写手必须先读它再动笔**。
#     ⚠️ 为什么加这一步：过去注入包只有"去读模板X"的指路牌、没有一句真人原句，
#        写手拿到的其实是"抽象要求"，文风等于没受控；缺档时更是连一行提示都没有（静默失效）。

# ② 子代理「写手」：注入包 + 作者细纲 + 对应档靶板（不喂历史对话）→ 写正文文件
# ③ 主会话：跑门（M1~M7，--out 写 UTF-8 报告）
python scripts/run_gates.py --chapters chapters --terms "术语表_书名.txt" \
    --tables "设定表_书名.xlsx" --genre "西幻/异世界" --out "09_机器门报告.txt"
# ④ 门红 → 子代理「修稿人」：门报告 + 正文，逐条修（不改剧情）
# ⑤ 子代理「恶人编辑」：三问 + 拼接六链（投喂 references/11_恶人编辑_子代理审核包.md）
# ⑥ 子代理「改稿人」：按打回意见改；禁止机械替换造翻译腔
# ⑦ 主会话：复跑门 → 导出 txt → 回填设定表 → 记账
```

### 子代理 prompt 三条纪律
1. **写手**：只喂「注入包＋细纲＋目标档靶板」；不喂历史对话。
   **注入包的「最小范本集」是写手唯一必然拿到的真人原句**——派活时明写
   “先读范本把节律定住，再读注入指令”；**没带范本的注入包不得派给写手**（见 ①-b）。
2. **改稿人**：禁止机械替换（反例「购买你／含在口中／站立在路灯底下」）；自然度优先于指标。
3. **所有子代理**：回报「改了什么＋为什么＋残留」，**保留原文件**（新建终稿文件）。

## 二、门（详见 `references/00_门速查卡.md`）

**M1 语感**｜**M2 节奏**｜**M3 卫生**｜**M4 重复与配额**｜**M5 账本**（表同步→事实→语癖卡，顺序硬约束）｜**M6 流程**｜**M7 分布与漂移**（上下限双向）
**人工门**：H1 风格锚定／H2 声音语癖（遮名测试）／H3 水文纪律／H4 恶人编辑。
**字数**：≥2,500，<3,000 章 ≤ 前 10 章数的 40%，**不设上限**。

## 三、三条硬约束

1. **规则准入**：新门/新判据必须经作者评审＋补回归测试（`scripts/回归测试/run_regression.py`）才生效。
2. **账本先行**：每章新增道具/事件/获知 → 先改表，再改正文（M5 顺序）。
3. **注入物**：人确认的类目优先；未确认的按垂直领域自动注入；病灶库默认注入（精简为 Top5）。
