# 章纲（模板）+ 单章结构

> 每章动笔前 5 分钟填一张。细纲是给作者看的蓝图：全要点，不展开成叙事。
> 【来源】六问框架为墨澜工程实践；节拍与 func 位参考题材卡（B 级，开局段最可靠）。

## 章纲：第 N 章
- 章目标：（本章在主线上推进/解决了什么，一句话。写不出这句话，这一章不该存在）
- 场景清单（2~4 场，每场至少做两件事）：
  1. 场景A：地点/在场者 → 推进____ ＋ 兼做____（立人物/埋伏笔/给信息）
  2. 场景B：……
- 冲突：谁想要什么、被什么拦住、结果如何（拦路力量必须来自已有设定，不凭空发明）
- 信息差设计：读者知道____，主角知道____（知而不知=揪心/悬念，全知=该摊牌）
- 看点落位：本章爽点/悬念/情绪高点放在第几场景
- 钩子（四选一，别连用同一种）：危机切断 / 新信息 / 预期反转 / 收获停半
- func 标注：本章新增冲突条目（type + intensity + func），连续 3 章无 3 级以上冲突 = 节奏塌陷预警
- 伏笔操作：埋 F0xx / 提及 F0xx / 回收 F0xx（写完同步台账）

## 单章结构（2000~3500 字通用骨架）
| 段位 | 字数占比 | 任务 |
|---|---|---|
| 开场 | ~15% | **进场即事**：第一段就有人做事或开口，不铺环境开场；紧接上一章结尾的时间线 |
| 发展 | ~40% | 冲突升温：1~2 个小转折；信息随动作给出，不说明书 |
| 高点 | ~30% | 本章看点兑现：冲突顶点 / 爽点 / 反转——用场景的"当众性"放大（有见证者） |
| 收束+钩 | ~15% | 落点收束（动作完成/对话收口/情绪落地），末段独立短行抛出钩子 |

## 写作红线（写完逐条对照）
1. 只写本细纲规定的节拍，不自由发挥
2. 不提前揭底未回收伏笔
3. 不新增人物表以外的重要人物/设定
4. 姓名、身份、称呼、伤势、位置与人物表/上一章一致
5. 时间线从上一章结尾接着走，不复述前文
6. 已解决的冲突不重复解决；已回收伏笔不再使用；宁可留白
