# 猫腻 文风语料（4 本，style 七维逐本原文 + anchors 金句）

### 大道朝天（仙侠｜score 5）
- 开局: 大能重生反向开局：先以众人之眼抬升「最强者飞升」的斩天奇观，主角却是没看完典礼的失忆重生者，以不会生火的仙师这一落差走进凡间
- 视角: 第三人称多视点镜头式切换（赵腊月、孟师、白衣少年、村民），叙述冷静零评判
- 句式: 短句短段为主，一句一段制造停顿，标点留白多，节奏如诗
- 对白: 对话占比约三成，台词极简带警句化，一句立人设一句翻钩
- 用词: 清冷诗意语感混现代口语（火锅、愿蘑菇丰收与魂火剑意同框），去雕饰的毛腻式文青仙侠腔
- 密度: 低动作密度高意象密度，事件推进慢但信息满格，靠留白承重
- 基调: 外冷内热，超然疏离中藏一丝黑色幽默与少年气的暖
- 签名: 杀人戏日常化（火锅与血、毛肚与魂火并置）；主角视点后置先画背景板；一句台词立威定设定；卷首题记「如果人生能够重来」点题
- 金句: 如果人生能够重来，我大概还是这样。；我是外门弟子，没有剑。；茫然想道，入门口诀是什么来着？
- 公式: 先举众生之眼抬出一场斩天飞升的绝世神话，再让神话本人以失忆重来之身落地，用不会生火的仙师反差进村伏笔，开启重走…

### 庆余年（历史｜score 5）
- 开局: 穿越转生楔子式开局：临终好人一夜成婴，血案+黑骑士救场立权力与武力谱系，随后跳四年进日常铺垫流，以信息差喜剧养长线悬念
- 视角: 第三人称限知贴身范闲视角为主，楔子用全知镜头与婴儿内视角交错，制造「读者比场内强者知道更多」的信息优势
- 句式: 中短句为主，大量省略号独立成段做分镜停顿，段末常押一句吐槽或金句收口
- 对白: 对话驱动叙事：楔子瞎子跛子互呛各一句「你似乎只会杀人」，第一章孩子王腔与奶音错置，台词承担人物关系与幽默
- 用词: 白话网文腔混现代梗（盗版影碟、YY小说、言情小说男主角）与古语词（别院、法杖、硬弩），古今错位即笑点
- 密度: 前密后缓：楔子万字塞进转生、血案、世界观、谱系四类信息，一、二章降速铺日常与功法，三章一张一弛
- 基调: 黑色幽默打底，开局「人生寂寞如狗屎」的丧与荒诞，转成市井轻喜，喜感表面下埋冷杀与阴谋
- 签名: 正经吐槽体：最残酷的事用最痞的语气说（好人没什么好报、蒙住双眼也蒙住这天），旁白插科打诨但关键意象一次到位
- 金句: 觉得人生真是寂寞如狗屎；新的身份，不被打扰的人生；蒙住了他的双眼，也蒙住了这天
- 公式: 将死好人魂穿血案遗孤：双守护者护体+从婴儿开练的顶配金手指，在港口别府装傻发育，用身世谜团吊住日常铺垫，静待入…

### 将夜（玄幻｜score 5）
- 开局: 神秘遗孤+市井崛起流开局：满门抄斩夜换尸逃生的孩子长成边城兵痞，以不明来历与'能活着'的异质进入大人物视野。
- 视角: 第三人称多视角跳切：荒原三行走—长安屠门—渭城军营，蒙太奇式开场
- 句式: 长短句相济，冷静白描中藏机锋，节奏从容有文学质感
- 对白: 对白占比约三成，多短促带机锋，对白即性格
- 用词: 文白相济、干净克制，猫腻式冷幽默与哲思句穿插
- 密度: 中高密度，三章内铺开三重时空与数条悬念，信息藏而不漏
- 基调: 苍凉冷静中带狡黠暖意，黑夜将至的宿命感
- 签名: 多线蒙太奇开场、'因为看见，所以恐惧'式哲思金句、市井细节反差神性背景、悬疑驱动的身世线
- 金句: 因为看见，所以恐惧。；蚂蚁能爬过，长肢虫能跳过，黄羊能跃过，鹰能飞过，只有人不能过。；想开一些，整个渭城……不，这整个天下，谁能赢我宁缺？
- 公式: 满门抄斩遗孤化身市井兵痞，以书法异禀与战场活命能力层层惊动大人物，向书院与身世真相行去。

### 择天记（玄幻｜score 5）
- 开局: 废柴改命流开局：先天经脉不连、注定早夭的弃婴少年，背负三千卷道藏底蕴下山进京，以退婚反杀开局对抗注定之命
- 视角: 第三人称，序章全知俯瞰，正文在徐府众人观察视角与长生限知视角间切换
- 句式: 长短句相间，短句铺陈画面，分节留白多，节奏舒缓有古意
- 对白: 对白占比中等，序章近乎无对白，正文对白承担机锋交锋与误会错位
- 用词: 文雅干净的书面语，古雅连接词多，无网络腔
- 密度: 高但克制，世界观随场景自然渗出
- 基调: 清冷沉静中带少年意气，宿命感与温暖并存
- 签名: 猫腻式慢热白描与分节留白；改命母题句；古语单音节神秘设定；以茶、行李、笠帽等物写人
- 金句: 你的命……真的很不好。；我不是，但我也想试试。；我本来就是来退婚的。
- 公式: 命定早夭少年+道藏底蕴与龙缘身世+退婚局反杀门第羞辱+被压→底蕴反杀→解身世谜→向天道改命
