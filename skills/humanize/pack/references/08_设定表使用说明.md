# 13 设定表 · 主题 → 大纲 → 细纲 → 角色

> 何时读：**开新书填 12 张表时**｜适用题材档：**全题材**


> 配套《规则书_V0.30.md》。这九张表是**流水线的上游**：表填完，机器门才有输入。
> 生成器：`_build_tables.py`（改字段后重跑即可，两个 xlsx 会覆盖重生成）

## 一、文件清单

| 文件 | 用途 |
|---|---|
| `设定表_模板.xlsx` | 空白模板（10 个工作表：填写说明 + 九张表，带下拉与冻结窗格） |
| `设定表_示例_我的魔力要分期.xlsx` | 用实测稿《我的魔力要分期》填好的示例（黄底=示例数据，可直接改） |
| `_build_tables.py` | 生成器（字段改动后重跑） |
| `export_beats.py` | 把「章节细纲表」导出成 `tail_check.py --beats` 能读的 beat 文件 |
| `设定表_示例_我的魔力要分期_beats.md` | 上面导出的示例产物（可直接喂门2） |

**新书怎么用**：复制 `设定表_模板.xlsx` → 重命名为 `设定表_<书名>.xlsx` → 按下面顺序填 → 导出 beat → 跑门。

## 二、填写顺序（别跳步）

1. **主题定位表** — 先回答"这本书是什么、写给谁、承诺什么"。这一张定了，后面才有判据。
2. **主角设定表 / 配角设定表** — 人物声音（语癖卡六列）在这里定，生成阶段直接注入。
3. **世界观速查表** — 写"硬约束"，防自相矛盾；术语行同步进 `11_skills包/术语表_<书名>.txt`。
4. **卷总纲表** — 分卷目标 + 每卷的爽点/失败/疲惫分配。
5. **万字节点表** — 每万字必须发生什么，长文失速的预警线。
6. **章节细纲表** — 逐章 beat sheet。**这是最关键的一张**，"情绪崩口位/蓄势位"两列缺一不可。
7. **伏笔钩子台账** — 埋了什么、何时回收、能否逐字（母题才可逐字）。
8. **节奏查询表** — 逐章节奏档位；右侧自动统计失败章间隔、谈判闭环占比、疲惫段数。

## 三、每张表喂给哪道机器门

| 表 | 关键列 | 机器门 |
|---|---|---|
| 章节细纲表 | 情绪崩口位 / 蓄势位 | **门2** `tail_check.py --beats`（缺字段直接打回） |
| 章节细纲表 | 本章新增术语 | **门6** `lint_check.py`（术语表自动发现，缺表打回） |
| 主角 / 配角设定表 | 口头禅 / 句长 / 标点 / 损法 / 称呼 / 禁用 | **门5** 锚定比对 + 第九节遮名测试 |
| 伏笔钩子台账 | 类型 / 回收方式 / 是否入白名单 | **门7** `dup_check.py --whitelist` |
| 节奏查询表 | 失败章 / 疲惫段 / 冲突解决方式 | **门8** 失败章间隔3~20不固定、谈判闭环≤2/3 |
| 万字节点表 | 平台节奏点 | 第3章主钩子、第5章第一爆点硬命中 |
| 世界观速查表 | 术语 | 门6 术语密度 + 门5 设定漂移 |

## 四、闭环命令

```powershell
# 1) 细纲表 → beat 文件
python agent文章V2/13_设定表/export_beats.py "agent文章V2/13_设定表/设定表_<书名>.xlsx"

# 2) 跑门2（尾巴落位：崩口位/蓄势位是否真落位）
python agent文章V2/03_评分与校准/tail_check.py --files "agent文章V2/12_实测/chapters/*.md" `
       --beats "agent文章V2/13_设定表/设定表_<书名>_beats.md"

# 3) 术语表（从世界观速查表抄出术语行）
#    写入 agent文章V2/11_skills包/术语表_<书名>.txt（每行一个正则）
```

## 五、依赖

`openpyxl`（`python -m pip install openpyxl`）。生成器与导出器都是纯 CPU、无网络。
