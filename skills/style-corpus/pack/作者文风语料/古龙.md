# 古龙 文风语料（12 本，style 七维逐本原文 + anchors 金句）

### 多情剑客无情剑（武侠｜score 5）
- 开局: 诗意冷开场双雄会：先雕人葬雪的病美人车中亮相，再让铁片剑少年踏雪入场，客栈杀局里两条线一合，即成知己
- 视角: 第三人称而深跟李寻欢心绪，对阿飞则纯用外视角观察留白，制造神秘
- 句式: 极短句与单句成段主导，格言化判断句收束，长短错落近现代诗
- 对白: 对话约占四成半，酒话见性见理，杀场对白短如刀，一句一定音
- 用词: 诗性比喻（冷风如刀、苍穹洪炉、响尾蛇眼）加反复咏叹句式，命运的复沓感
- 密度: 高而不挤：雪原、对话、进店、杀局四拍，每拍各给一个金句与一个悬念，文武双线并进
- 基调: 孤独苍凉、杀伐中有深情，全程低频忧郁底色
- 签名: ['对偶比喻式电影片头开场', '留白式一击：只写结果不写过程的高手美学', '判断句金句收段、单句成段的节奏控制']
- 金句: 冷风如刀，以大地为砧板，视众生为鱼肉；我的剑是用来杀人的！；那玩具实在太危险了
- 公式: 诗意冷开场让双主角各自带伤入场→用反派的嚣张吹牛做铺垫→两场一击必杀立双雄→金句与身世之谜钩住知己同行

### 大地飞鹰（武侠｜score 5）
- 开局: 极限生存危机开场：沙漠绝地上人与食尸鹰互等的生死对峙，引入『等你死』的神秘尾随者，再让第三方箭劈而入形成三方角力
- 视角: 第三人称限知紧贴小方视角(读者与他同步挨饿、同步初见卜鹰与屠场)，开篇数段近似无人称寓言镜头
- 句式: 极短句独段为绝对主力，一句一段、警句回环；中长句点缀，短中≈7:3
- 对白: 对话占比约55%，苏格拉底式辩难(等死/送剑/石米是猫)——辩论同时完成情节推进、哲思输出与人物互认
- 用词: 冷硬、思辨、口语极简净，偶用奇喻(『沙漠就像是个最多变的女人』)点睛
- 密度: 高：人鹰对峙、卜鹰身份、怒箭登场、黄金劫案、猫盗屠场五重信息层层压进万字内
- 基调: 荒寒肃杀中夹黑色幽默，杀气和达观同炉
- 签名: ['寓言式开场：人与食尸鹰彼此等对方先死', '短句轰炸+一句一段的排版节奏', '侧面认证悬念：借卫天鹏之惧、苏玛之疯抬出卜鹰与猫盗的神秘段位']
- 金句: 只剩下了一柄三尺七寸长的剑和一条三寸七分长的伤口；我这一辈子从未要过活人的东西；如果我是猫盗，现在你就已是个死人
- 公式: 生死寓言开场：让主角与秃鹰共享一个濒死镜头→尾随者『等你死』式登场，靠送剑拒剑之辩互照灵魂→第三方破空一箭试探…

### 天涯明月刀（武侠｜score 5）
- 开局: 孤狼赴死局开局：天下第一刀客独行死镇，等一场一年之约的杀与不杀
- 视角: 第三人称，视角在傅红雪与燕南飞间摆荡，旁白多设问
- 句式: 极短句、独句成段，诗化复沓与问答推进，节奏如更鼓
- 对白: 对白占比高，冷峻机锋、答非所问中藏杀机与深情
- 用词: 极简意象化：天涯、明月、死亡、寂寞、苍白与漆黑
- 密度: 低到中，大量留白与停顿，一句一顿
- 基调: 苍凉悲怆孤绝
- 签名: 独句成段的断裂排版、颜色对位修辞（白手黑刀红剑）、更鼓报时的结构刻度、楔子问答体、“不闻不见不动”三连
- 金句: 他的刀如天涯般辽阔寂寞，如明月般皎洁忧郁；苍白的手，漆黑的刀！；我不愿让你死在别人手里。
- 公式: 孤死刀客+无敌快刀+赴死之约与重金买凶+连环杀局一刀破局的循环

### 七种武器系列·拳头（武侠｜score 5）
- 开局: 愤怒浪子受雇开局：以拳头和悍勇立威的伤心人，被神秘富女以激将与秘辛相诱，充任穿越死地狼山的保镖，身上带着剑伤与情伤。
- 视角: 第三人称贴小马，间以全知旁白的箴言式插议
- 句式: 古龙式短句短段，一行一段，断句制造节奏与惊愕
- 对白: 对白占比极高，一问一答的机锋推进剧情并完成人物互探
- 用词: 白话洗练，多悖论警句与'据说''传说'式的江湖传闻腔
- 密度: 中高：事件推进快，情绪与闲笔穿插稀释而不滞
- 基调: 表面嬉笑怒骂，底色是浪子的孤独与刻骨情伤
- 签名: ["'很好是什么意思'的重复梗", '穿衣服洗澡的女人', '愤怒的小马人设自我注解', '想笑就笑的浪子哲学旁白', '数字式自嘲（毛病三千七百八十四点）']
- 金句: 一个人若想笑的时候都不能笑，活着才真是没意思得很。；别人要你做的事，你偏偏不做；不要你做的事，你反而偏偏要做。
- 公式: 愤怒浪子+一双拳头+亡命护送+悍勇破局幽默收尾的循环

### 赌局系列（武侠｜score 5）
- 开局: 决战赌局悬念开局：神秘赌局押五十万两黄金赌两大剑客黄鹤楼生死决，财神、秃鹰、大红袍等枭雄借'验货'层层入场
- 视角: 第三人称说书人视角，多机位群像切换，档案式引入人物
- 句式: 古龙式短句分段，问答推进，节奏如刀，常以断言警句收束
- 对白: 对白约占六成，斗嘴机锋与身份试探为主功能
- 用词: 冷峻凝练、警句化，奇诡比喻与黑色幽默并置
- 密度: 中高，人物档案与势力关系交代密集，悬念铺设快
- 基调: 冷峻奇诡中带戏谑，宿命感与赌徒荒诞相映
- 签名: 短句断行的古龙节奏；奇人异士档案式出场；以赌局写江湖的命运隐喻；自问自答的警句对白
- 金句: 只有黄金才是永恒不变的。；杀机一起，出手间就再也不会留容忍活命的余地了。；哪里有人将死，只有秃鹰才知道，死，有一种特别的味道。
- 公式: 神秘赌局押注剑客生死决，财神枭雄各方以信息与算计层层下注，于一局赌斗中兑现智斗与武戏

### 萧十一郎（武侠｜score 4）
- 开局: 悬念不见面开场：废柴式主角不出场，由两名女性/男性受害者与旧识轮番侧面烘托，'人未至而名先惊'的呼云托月式入局
- 视角: 第三人称，紧跟单一视角（前1万字全随风四娘），但大量作者旁白式心理断语自由插入
- 句式: 短句绝对主导，一句一段极多，中长句只在铺陈往事时用；问号高频（'是刀？''为什么？'）
- 对白: 对话占比约55%，功能是调情式过招与信息互探——每场对峙先打嘴仗后动手，对白承担大量人设与背景交付
- 用词: 冷硬口语混现代格言腔（'刺激最容易令人衰老''世上永远没有任何一样事能代替情人的手'），几乎不用文言
- 密度: 信息密度中等、留白极多：一章两桩血案一条旧情；节奏外缓内急，靠悬念问句推进
- 基调: 香艳开场、寂寞底色，苍凉中带潇洒
- 签名: ['呼云托月侧写：主角两章不出场，全靠被他伤过的人抬咖位', '一句一段+问句连击的呼吸感排版', '场景定人：浴盆、石墓棺材两个奇观场景完成风四娘与飞大夫的全部人设']
- 金句: 她喜欢骑最快的马，爬最高的山，吃最辣的菜；好好的一双手不用来绣花，却用来杀人；萧十一郎！
- 公式: 以一名风情万丈的女配开场立威，随即让两位江湖顶级高手先后承认被书名主角所伤——主角本人不出场，仅凭'砍过谁'的…

### 那一剑的风情（武侠｜score 4）
- 开局: 俏皮女子游戏开场渐入大案：先似整蛊小气的市井喜剧，神秘流浪汉、毒宴与老臣劫狱委托层层剥出陈年阴谋；男主以情变线中点切入
- 视角: 第三人称，藏花线与杨铮线交替推进；说书人偶尔下场列举品评(群芳谱式盘点女中豪杰)
- 句式: 短句独段为主，破折号省略号转折；中长句穿插铺陈，短中长≈5:4:1
- 对白: 对白占比约60%，斗嘴机锋、互相试探即是情节本体；藏花与杜天的问答控制全章节奏
- 用词: 武侠切口混俏皮白话，夹西洋器物掌故(波斯地毯、转桌、鸡尾酒)，俗中藏雅、谐中带锋
- 密度: 中高：万字内立女主、揭两重隐士身份、抛出劫狱委托与两桩陈年谜案、再开男主情变线
- 基调: 前两章明媚俏皮、越往后越阴沉，明面是笑、底色是谜
- 签名: ['赌局反转结构：末秒『摔下来』的动作细节充当翻盘支点', '器物技艺开场立人(温酒讲究火候温度时间——手艺即身份与敬意)', '串场彩蛋式排比(点名风四娘、高亚男、燕七、朱七七等旧作豪杰来衬托藏花的『狂』)']
- 金句: 藏花的心情愉快极了，可是天气却坏透了。；我更想证明爬树并不是男人专利；这把剑已二十年未饮人血
- 公式: 整活立女主：一场设给小气鬼的赌局用细节反杀赢全场→毒宴与温酒的手艺逼出隐藏身份的老臣→递上一桩自相矛盾的陈年劫…

### 大人物（武侠｜score 4）
- 开局: 大小姐出走流开局：深闺少女为嫁“大人物”扮男装闯江湖，以天真撞向真实江湖
- 视角: 第三人称全知，叙述者常跳出对读者插话点评
- 句式: 古龙式短句，分段极短，排比与问答推进
- 对白: 对白占比极高，主仆斗嘴承担几乎全部信息与趣味
- 用词: 俚俗俏皮与诗化抒情交替
- 密度: 中，信息由对话层层抖出，节奏轻快
- 基调: 轻快浪漫带少年气
- 签名: 红丝巾意象复沓、数字递进（108/216/324刀）、“你说危险不危险”式叙述者插话、章名趣味化、对白近于全篇
- 金句: 系上这红丝巾，就表示你决心要奋斗到底，死也不能在任何人面前示弱！；秦歌就是秦歌，永远没有第二个。以后没有，将来也不会有！；他挨了三百二十四刀。
- 公式: 天真大小姐+侯府身份与胆量+逃婚闯江湖+听传奇、遇险、辨真假大人物的成长循环

### 楚留香系列·血海飘香（武侠｜score 4）
- 开局: 名盗预告行窃开局：踏月留香的挑衅预告戏当众兑付，海上连环浮尸谜案双线同启
- 视角: 第三人称全知，京师盗宝现场与海上日常双线切换
- 句式: 古龙短句分段，侦探式细节铺陈，每具尸体推进一步
- 对白: 对白占比高，机锋调笑与案情推理对答各半
- 用词: 俏皮风雅与悬疑惊悚并用，人名诨号琳琅
- 密度: 中高，尸体即信息，考据式对话密集投放线索
- 基调: 潇洒明快中透诡异
- 签名: 留香短笺与郁金香香气意象、三美婢功能化配置、以尸证推凶的推理链、“你等瞧吧”的预言口吻、诗化章名
- 金句: 公子伴花失美，盗帅踏月留香。；今夜子正，当踏月来取，君素雅达，必不致令我徒劳往返也。；越凶险的闲事，管起来才越有趣；牵连越广的秘密，所牵连之物价值也必定极高。
- 公式: 风流盗帅+轻功与智囊团+连环互杀谜案+预告戏耍与追凶升级的循环

### 欢乐英雄（武侠｜score 3）
- 开局: 反套路人物素描开场：废柴(实则全能)落魄英雄的荒诞履历喜剧，怪人聚义于空庄，随后沉默神秘者倒挂入局
- 视角: 第三人称+说书人高频下场锐评(『你』『我们这位英雄』『所以我相信你一定喜欢』)，与读者勾肩搭背
- 句式: 警句短句领起(王动却不动)、骈偶排句铺张、中长句补叙，短中长≈4:4:2
- 对白: 全篇对白占比约40%，燕七登场后升至55%以上；对白即笑点本体，郭王抬杠(『躺着喝酒会不会从鼻子里喷出来』『我试过』)全靠节奏
- 用词: 口语、烟火气、反讽夹警句，大俗中见哲理(『胖子既然可能变得很瘦，富贵山庄也可能变得很穷』)
- 密度: 中低：情景剧式闲笔，但闲笔全砸在人物上，万字立住两大主角+引出第三人
- 基调: 欢乐荒诞、温暖嘲讽，穷得快乐的生命礼赞
- 签名: ['命名对偶立人设(郭大路人行其『名』四处乱动/王动偏『不动』)', '夸张排比绝句式搞笑(『有人甚至认为他除了生孩子外，什么都会』)', '说书人下场插科打诨掌控节奏，把旁白写成第四个角色']
- 金句: 王动却不动。；除了生孩子外，什么都会；强盗遇见穷鬼，也只有自认晦气
- 公式: 反套路穷侠开场：先写他什么都会、就是穷得要命，落差造笑→一次荒诞夜袭让泼皮遇见懒鬼，当剑换酒结为兄弟→穷欢乐日…

### 霸王枪（武侠｜score 3）
- 开局: 综武穿越+系统流：现代灵魂穿越唐伯虎觉醒记忆与阅历值系统，温柔乡中苟着刷阅历备战世仇
- 视角: 第三人称单主角限知，第五章起切内宅女视角双线并行，系统面板直接入文
- 句式: 短句短段为主，一句一行，网文快节奏切分
- 对白: 对白直白带网感，内宅用'相公/奴家'式古风甜语，旁白常吐槽
- 用词: 口语白话，量词数字多有缺失脱漏（源文本错字与广告水印残留）
- 密度: 一章一事件，信息密度中高，爽点间隔短
- 基调: 轻松爽文，种田日常与苟道复仇并行的诙谐味
- 签名: 系统'叮'提示音、章末'求收藏'、炸鸡翅、含笑半步癫等梗反复出现
- 金句: 【叮，阅历值系统觉醒，请查收。】；堂堂邀月宫主，竟然心甘情愿和其他女子共享一个丈夫？说出去都没人相信！；在这个世界，儒家孔圣人可不是什么文弱书生。千百年前，他可是一位以武证道的绝世高手！
- 公式: 穿越综武成唐伯虎，靠读书刷阅历苟升境界，家里蹲着女魔头夫人，攒够实力清算灭门世仇

### 失魂引（武侠｜score 3）
- 开局: 凶宅奇案开局：富贵侠少夜游误入满门被屠的诡异山庄，连环异变与失忆谜团接踵而至
- 视角: 第三人称限知，紧贴管宁的所见与心理
- 句式: 早期古龙，句式偏长，四字格与文言残留，环境铺陈渲染浓
- 对白: 对白占比中低，以叙述、心理独白为主，对白仅关键交锋
- 用词: 古雅惊悚，月夜、灯光、血渍意象反复
- 密度: 中，环境与心理铺陈多，信息靠尸身细节递进
- 基调: 诡秘惊悚凄清
- 签名: 头顶血洞的连环死状、“我是谁”失忆梗、以景结情的月夜描写、自我对话式心理（“管宁呀管宁”）、数字对应推理
- 金句: 我是谁？我是谁？……；星白如月，月白如风，只有地上的血渍……血渍该是什么颜色呢？；我七年读书，三年学剑
- 公式: 富贵侠气少年+推理胆识+误入血案现场+武力碾压下层层诡异翻案的悬疑循环
