# 云中岳 文风档案

> 语料来源：《甘十九妹》《铁胆兰心》《饮马流花河》《黑豹传奇》《绝尘山庄》《矫燕雄鹰》《风尘豪侠》共 7 本。
> 定位：市井写实武侠代表。与金庸（庙堂史诗）、古龙（诗化浪子）、司马翎（智斗权谋）的根本分野在于——**把武侠摁回地面**：行当考据、底层视角、扮猪吃虎、民生疾苦。
> 用法：写"云中岳味"的武侠时，按本文各节的规律取用；金句区用于校准语气，创作参考区用于直接执行。

## 风格核心（3 句话）

1. 云中岳的核心竞争力是"市井写实"：用制度与行当考据（停刑日、巡检司、大明宝钞）+ 北方市井口语群像，让江湖长在真实社会的土壤里，而不是悬空的门派谱系里。
2. 他的主角几乎全是"藏起来的强者"——装昏挨打的游侠、捉兔喝酒的隐者、衣衫寒酸的蠢汉、单骑穷儒，靠"扮猪吃虎—受辱—露底翻盘"的循环制造爽感；爽感之下压着官匪勾结、贩奴夺地这类现实黑幕。
3. 文体上是评话说书体与写实长段的混合：绵密长句铺市井风情与地理沿革，关键处三字短句刀截，旁白议论、市井对白、旁人侧写三管齐下，节奏"闲笔慢铺、杀局陡快"。

## 市井写实写法（招牌）

云中岳最不可替代的一手，是让武侠"落地"：

- **制度考据嵌入叙事**：《风尘豪侠》嵌入"停刑日、巡检司、大明宝钞"等明代制度词，一章内完成"地理、制度、黑幕、人物"四层铺设。考据不是掉书袋，而是给黑幕提供现实支点——王法有辖区、有失灵处，侠才有出场的空隙。
- **行当与地理志式铺陈**：《矫燕雄鹰》的签名之一是"江湖行当与地理考据"；《风尘豪侠》"地理沿革与风物铺陈细致"。主角每到一地，先写镇子、店家、行情、边地风物，再出事。
- **社会派黑幕**：冲突源头几乎都是民生问题——官匪勾结强夺田产（《铁胆兰心》）、边地牧场奴工（《风尘豪侠》）、押俘血案（《饮马流花河》），而非武林秘籍与神功宝物。"王法，一文制钱一斤"式的台词把司法失灵直接写进对白。
- **底层人物开卷**：老门房、店伙、乡民、猎户常是开场视角。《甘十九妹》先以老门房与褪色金匾铺"盛极而衰"的末世感；《风尘豪侠》用店伙旁人侧写主角——让卑微的眼睛先看世界，主角才从人群里"显形"。
- **落魄感的美学**：主角的外壳永远是寒酸的——装昏挨打、捉兔喝酒、衣衫寒酸、单骑穷儒。体面被剥掉之后，剩下的才是真本事与真人格。

## 视角与人称

- 主流是**第三人称全知/多机位轮切**：《甘十九妹》多机位（门房、湖船、厅堂、茅亭），镜头始终围着同一张杀戮网收拢，形成"多空间蒙太奇（船—厅—亭）同步收紧死局"的签名；《矫燕雄鹰》视角在豪客群像、名剑客、贫衣青年之间轮转；《风尘豪侠》说书式调度，兼用店伙等旁人侧写主角。
- **先群像后聚焦**：《饮马流花河》先市井群像闲笔，后聚焦君客人与绿衣姑娘；主角在群像里"潜伏"到露底为止——视角的聚拢节奏就是悬念的释放节奏。
- **说书旁白承担讲解**：《黑豹传奇》"夹大量旁白解说人物心境与江湖常识"；《甘十九妹》有"评书式插话旁白与哲理性顿点（对死亡与黑夜的议论）"。旁白负责讲规则、评人物、埋顿悟，是云中岳的"说书人声带"。
- 例外档案：《绝尘山庄》是第一人称女性视角吐槽流轻文（"NND""哟嚯"式语感，短句短段）——说明"说书全知市井体"才是云中岳本体；模仿其文风时勿取此本，此本仅作风格边界标注。

## 句式与节奏

- **绵密写实长段为主**：长句多铺陈、叙述夹议论、章回式分段（《矫燕雄鹰》）；地理风物可细到沿革出处（《风尘豪侠》）；《铁胆兰心》"市井对话与场面白描并重，节奏稳健"。
- **关键处短句刀截**：《甘十九妹》"感叹与省略频用，关键处三字短句刀截（『太晚了！』）"——铺陈与刀截的比例，大约是十段铺垫换一刀，刀必须落在底牌掀开的瞬间。
- **闲笔—杀机强反差**：《饮马流花河》"闲笔铺陈市井风情后陡然提速写打斗"；寒冬桃花的谶语式闲笔与五花大绑反杀的暴烈开场同章并存——闲笔越闲，杀机越冷。
- **评话口语腔**：市井白话加评书套语（敢情、一看之下），感叹与省略频用（《甘十九妹》）；"有道是""俗语说"是引出狠话与道理的标准起手。
- 节奏总模型：**慢起（市井闲笔/群像）→ 加压（受辱或血案）→ 提速（露底/杀局）→ 收束议论（哲理顿点）**。密度上"一节三波杀局，人物、毒物、阵法、底牌全部到位，几无闲笔"（《甘十九妹》），但闲笔集中花在开卷市井风情上。

## 对白写法

- **占比高**：约三至四成——《甘十九妹》约三成，《矫燕雄鹰》约四成，《黑豹传奇》"极高"，几乎靠对话推动情节。
- **市井粗口与乡谈鲜活**（《铁胆兰心》），对白"承担恶霸横行与背景交代"；京味口语鲜活、对白见性格与身份反差（《饮马流花河》）。
- **功能化到冷酷**：《甘十九妹》杀局章的台词"每段只干两件事：杀人或加危机"——凶手呛话、败方议事、弟子报丧各司其职；寒暄也是布局的一部分。
- **三职对白**（《矫燕雄鹰》）：情报交换、人物定性、江湖规则讲解——云中岳用对白代替设定说明书。
- **口头禅与语言毛病做人设**：老者"浑小子"骂口成癖、聂十八一惊就结巴重复（《黑豹传奇》）——用台词习惯代替外貌描写做记忆点。
- **引语式威胁/宣言**：先引俗语再放狠话（"俗语说：杀人偿命，欠债还钱……你们等着好了"），先把市井道理占住，再占上风。
- **身份反差藏在对白里**："我根本就没想跑。如果我真的要跑，你也追不上。"——装闲人者一开口，深浅立判。

## 用词底色

- **市井白话 + 评书套语**：敢情、一看之下、浑小子、有道是、俗语说、此地不留爷自有留爷处。
- **行业词/制度词**：停刑日、巡检司、大明宝钞、总镖头、押俘、牧场奴工、门房。
- **明代生活词**：制钱、银两、庙宇、金匾、边地边荒、店伙、田产。
- **雅俗并置**：市井俚语与文言雅句交融（《饮马流花河》"雅俗并置"）、白话典雅混合（《风尘豪侠》）、"传统武侠书面语，市井行话与考据味并存"（《矫燕雄鹰》）。
- **杀场不用血腥堆砌，用感官间接词**：异香、血水、涟漪（《甘十九妹》"初嗅时，极似秋日的桂花香气味"）——美与酷烈交叉剪辑，是反派立威的标配笔法。

## 打斗写法

- **一招定胜负的写实流**（《风尘豪侠》签名）：不写回合数与招式名词，写结果与身份反差——"被女杀手寻衅时一招制敌深不可测"（《饮马流花河》）。
- **干净利落美学**："杀起人来干净俐落，不沾血迹"（《矫燕雄鹰》）；装昏者"他如果运起劲，恐怕比金刚还要硬"（《铁胆兰心》）——硬功藏在皮肉之下，打斗写的是"藏了多少"而非"打了多久"。
- **实战阵感**：《风尘豪侠》"打斗写实战阵感强"——比拼的是布置、地形、底牌与时机，而非内力境界。
- **打斗服务立威**：《甘十九妹》"船上截杀立反派不败之威"——先让反派赢得干净彻底，主角方从尸体堆里起步，翻盘才有分量；绝世高手也常以"装死试胆"的方式动手（《黑豹传奇》）。

## 情绪基调

- **民生疾苦压着暗涌的侠气**（《铁胆兰心》）：先抑后扬，冤情铺足、受辱到位，侠义出手才又痛又快。
- **苍凉写实 + 豪侠谐趣**（《风尘豪侠》）、"苍凉边地底色上暗涌惊险，闲适与杀机强反差"（《饮马流花河》）：主角带黑色幽默的痞气，苍凉是底色，谐趣是釉面。
- **阴冷肃杀与市井温情并存**：《甘十九妹》"阴冷肃杀的末世围城感，纸面透出生无可求的窒息" ↔ 《黑豹传奇》"诙谐轻松带惊悚噱头，冷幽默与市井温情兼具"——云中岳的悲悯不喊口号，藏在闲笔与骂声里。
- **底层小人物的挣扎与侠义的共存方式**：王法失效处，侠以"讨债人"身份出场（"吴某会向你们讨债的"）——侠义被翻译成市井人人能懂的债与偿；小人物不用成侠，只需在死局里攥住最后一张底牌（《甘十九妹》"卑微晚辈暗藏底牌与妙计"）。

## 开局写法（逐本签名开局）

- 《甘十九妹》：灭门倒计时——老门房+褪色金匾铺盛极而衰，船上截杀立反派不败，堡垒变毒烟死地。
- 《铁胆兰心》：扮猪吃虎——身怀绝艺的少年装昏挨打蒙混恶霸，暗查官匪勾结夺田冤情。
- 《饮马流花河》：绝世隐者——来历成谜的俊美青年隐居边地捉兔喝酒，冷眼旁观押俘血案，被寻衅时一招制敌。
- 《矫燕雄鹰》：寒酸"蠢汉"在名剑客面前认怂被踢，借荒寺夜局逐步露真容。
- 《风尘豪侠》：游侠行脚——单骑入边荒小镇惩地霸立威，背后压着明室夺位、护帝名单的朝野大局。
- 《黑豹传奇》：血布托付——少年撞尸林受千里送布之托，绝顶高手装死试胆一路相随。

共同结构：**先给主角一个最卑微的外壳 → 用一场别人的血案/冤情立起世界的恶意 → 主角露一手（或按兵不动）收束开章**。

## 情节公式（语料逐本 formula）

- 《甘十九妹》：名门被灭门开局 → 两路连杀立足反派不败 → 卑微晚辈暗藏底牌与妙计，拖延求生点燃复仇线。
- 《铁胆兰心》：游侠少年装昏受辱潜入受害村镇 → 以绝艺家财为底牌 → 限期内替乡邻扳倒官匪勾结的夺地恶霸。
- 《饮马流花河》：隐士高人冷眼旁观押俘血案 → 女杀手寻衅被一招制服 → 双方神秘身份之谜牵出江湖主线。
- 《矫燕雄鹰》：扮穷高手混迹名剑客与女杰之间 → 借荒寺夜局露底翻盘 → 以退为进的扮猪吃虎打脸循环。
- 《风尘豪侠》：持神秘名单的穷儒游侠单骑闯边荒 → 一路打脸贩奴地霸 → 寻访十二高手护帝抗鹰犬。
- 《黑豹传奇》：少年猎人受死镖师血布之托 → 绝世老怪装鬼试胆贴身相随 → 千里送布步步入局。

## 逐本七维速查（写分卷/同人时对照用）

### 《甘十九妹》（score 4）
- 视角：第三人称多机位轮切，镜头围同一张杀戮网收拢
- 句式：中长句评话口语腔，感叹省略频用，三字短句刀截
- 对白：约三成，台词只干"杀人或加危机"
- 用词：市井白话+评书套语，杀场用异香/血水/涟漪
- 密度：极高，一节三波杀局，几无闲笔
- 基调：阴冷肃杀的末世围城感，生无可求的窒息

### 《铁胆兰心》（score 4）
- 视角：第三人称，随柏青山视角观察村镇人情世态
- 句式：绵密写实长段，市井对话与场面白描并重，节奏稳健
- 对白：占比高，市井粗口与乡谈鲜活
- 用词：朴拙写实，北方市井口语浓厚
- 密度：中高，一章完成入村-受辱-认亲-冤情四层推进
- 基调：先抑后扬，民生疾苦压着暗涌的侠气

### 《饮马流花河》（score 4）
- 视角：第三人称，先市井群像闲笔后聚焦男女主角
- 句式：典雅京白，长短句错落，闲笔后陡然提速写打斗
- 对白：中等，京味口语鲜活，见身份反差
- 用词：雅俗并置，市井俚语与文言雅句交融
- 密度：中等，闲笔多但悬念埋设精准
- 基调：苍凉边地底色上暗涌惊险，闲适与杀机强反差

### 《矫燕雄鹰》（score 4）
- 视角：第三人称全知，豪客群像、名剑客、贫衣青年间轮转
- 句式：长句绵密多铺陈，叙述夹议论，章回式分段
- 对白：约四成，承担情报交换、人物定性、江湖规则讲解
- 用词：传统武侠书面语，市井行话与考据味并存
- 密度：中高，世界观、名号谱系（三龙四风七虎八鹰）、人物关系层层铺排
- 基调：冷峻写实的江湖世情，带黑色幽默

### 《风尘豪侠》（score 4）
- 视角：第三人称全知，说书调度，兼用店伙旁人侧写主角
- 句式：长句绵密，地理沿革与风物铺陈细致，实战阵感强
- 对白：中等，市井方言味浓，服务人情世态
- 用词：白话典雅混合，嵌入停刑日、巡检司、大明宝钞等制度考据
- 密度：高，一章完成地理、制度、黑幕、人物四层铺设
- 基调：苍凉写实中带豪侠谐趣

### 《黑豹传奇》（score 3）
- 视角：第三人称说书式全知，大量旁白解说心境与江湖常识
- 句式：说书体长句为主，节奏絮叨铺陈，偶插短句点睛
- 对白：占比极高，白话口语化；结巴复述+"浑小子"骂口成癖
- 用词：平实市井白话少雕饰，土语与旧武侠套语并用
- 密度：对话推动情节，铺垫细碎而画面感强
- 基调：诙谐轻松带惊悚噱头，冷幽默与市井温情兼具

### 《绝尘山庄》（score 3，风格变体，勿作模仿基准）
- 视角：第一人称女性视角，吐槽式内心独白
- 句式：短句短段，轻快跳跃，感叹与自我打趣交错
- 对白：现代口语混古风称谓，俏皮斗嘴
- 用词：网络轻文风（"NND""哟嚯"），比喻萌化夸张
- 基调：轻松萌欢、微甜微虐的少女向

## 创作参考：怎么写出"云中岳味"

1. **开卷先写地方再写人**：主角进场前，用一小段铺镇子地理、店家行情、百姓生计；让读者先闻到市井味，再让"蠢汉/穷儒/闲人"主角低调入画，并借店伙、门房等旁人侧写他。
2. **每章至少嵌一个制度/行当考据词**（如巡检司、停刑日、宝钞、总镖头、押俘），并让它直接参与剧情——王法到不了这里，才轮得到侠来讨债。
3. **冲突选民生黑幕**：夺田、贩奴、押俘、官匪勾结；反派先在市井层面积恶，主角的拳头才有正当性；"一句话：人不如畜"式的控诉由场景自己说出，不由旁白喊出。
4. **扮猪吃虎按三拍走**：受辱装怂（挨打/被踢/被讥）→ 旁人侧写其怪异细节（手茧、眼神、饭量）→ 一招露底翻盘；每露一次底，立刻换地图或换身份，维持"藏"的势能，形成打脸循环。
5. **反派必须先赢干净**：用一场截杀或灭门立反派不败之威（毒烟封死地、五花大绑反杀式开场）；主角方从卑微晚辈起步，靠拖延与底牌点燃复仇线。
6. **对白功能化 + 俗语开路**：每段台词只做"杀人、加危机、交情报、定人物"四件事之一；放狠话先引俗语（"俗语说……""有道是……"），用市井道理占理；给重要配角一个口头禅或语言毛病（骂口癖、结巴复述）。
7. **节奏按"慢铺—加压—刀截—顿点"**：长句铺风物与地理沿革；危机处切三字短句（"太晚了！"）；杀场用间接感官词（异香、血水、涟漪）而不用血腥堆砌；章末落一句哲理旁白收束（"对某些人来说，期待比死亡更痛苦"式顿点）。
8. **打斗只写一招与结果**：写实阵法感（地形、布置、时机、底牌），胜负一招定；胜者"干净俐落，不沾血迹"，败者的台词用来交代下一个危机。
