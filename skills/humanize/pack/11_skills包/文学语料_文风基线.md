### 四条决定性发现

1. **段长是最大差异：文学 112 字 vs 网文 30 字。**
   纯文学用大段落推进，网文用碎片段落。**这不是好坏，是两种语法**——但"像人写"的判据里，段长分布是强信号。
2. **方言在文学里近乎为零（0.04），在网文里 0.33~0.39。**
   → 我之前设的"西幻档 0.33"其实已经是网文口径；**文学口径是 0.04**。
   （某西幻 AI 稿实测 1.70＝两者的 4~40 倍，属书专属个案，已移出，不作通用参照。）
3. **破折号：文学 1.56、译本 1.57，网文 0.5~0.6。**
   → 若某稿实测低到 0.24 一类，**低于所有档**，这本身就是"被去AI味洗过"的痕迹（外部审查已指出）。
4. **欧化句式（翻译腔指标）1.6~1.7/千字**：
   检测口径 = `作为…的`／`被…所`／`对于…来说`／`在…上`／`当…的时候`／`一个…的`／`进行…的`／`关于…的`。
   这是**可量化的翻译腔基线**——学翻译腔，就对齐这个密度与句长（34字）。

## 三、怎么用

### 3.1 学文学文风
写"正经叙事段"时对齐：**段长 80~150 字、句长 26~30、burst 0.7~0.8、方言≈0**。
> 注意：网文读者不吃纯文学的段长（112字）。**不要直接照搬**——把文学档当"上限参照"，网文档当"下限参照"。

### 3.2 学翻译腔
写"异世界/异域感"的段落（或需要翻译腔质感的叙述）时对齐：**句长 34、欧化句式 1.6~1.7/千字、对话占比 0.15**。
> 反面用法：西幻若想显得"不是中文原生"，可以**适度**用欧化句式；若想显得"中文作者写的"，则压到 0.5 以下。

### 3.3 破折号/省略号
文学 1.56/1.57、网文 0.5~0.6 → **实测低于所有档即属"过度清洗"**（某西幻 AI 稿实测 0.24 即此例，书专属已移出）。建议回到网文档（0.5~1.5）。

## 五、现代科幻/奇幻文学 · 抓取受阻记录（2026-09-09）

目标：按作者指示补《死在火星上》一类**现代科幻文学**（适合作网文叙述层锚点）。

**已尝试、全部失败**：

| 源 | 结果 |
|---|---|
| ck101.tw（有《死在火星上》全文） | ConnectTimeout（被墙） |
| 微信读书 | 200 但需登录/JS |
| 起点/番茄/17K/刺猬猫/SF轻小说 | JS 渲染或付费，正文不可提取 |
| 努努书坊、久久读书、好读网、顶点、笔趣阁 | 连接重置/超时 |
| 蝌蚪五线谱、中国科普作家协会、科幻世界 | 200 但无正文链接（JS 渲染） |
| kapuxiaoshuo.com | 403（仅移动端） |
| ft.enwaxs.cc | 200 但正文提取失败（导航页） |

**结论**：现代中文科幻/奇幻文学**几乎全在付费墙或不可达域名后**，公版库（维基文库/古登堡）里没有现代作品。

**可行路径（待作者选）**
1. **作者提供文本**（epub/txt 放指定目录，我按同一口径做指纹分析）；
2. 作者给出**可访问的具体 URL**，我定向抓取；
3. 退而求其次：用**可访问的现代科幻网文**（如起点科幻频道）代替——但那又回到网文口径；
4. 暂不补，先用网文八档语域卡。
