> 一句话：**规则交给脚本，事实交给表格，判断交给作者。** 本包把"去 AI 味"拆成可执行的 7 个门族 + 4 个人工门 + 分题材文风靶板。

---

## 一、这个包解决什么问题

AI 写网文会被检测器/读者识别，通常表现为两类病：
1. **分布病**：句长齐、段长齐、情感平、修辞单一、困惑度低——已量化成门（M1~M7）；
2. **语域病**：无论什么题材都写成"现代中文网文腔"——已建 8 档**文风靶板**（`references/文风靶板_分题材/`）正面示范。

配套三件事实底座：**设定表 12 张**（道具/事件/人物已知信息等，跨章一致性靠它）、**术语表**、**配额/瑕疵清单**。

## 三、怎么跑（已实测可跑）

```powershell
cd skills_V0.4
# 跑 7 个门族（默认收敛输出；--verbose 恢复全量；--out 恒落全量报告）
python scripts/run_gates.py --chapters "samples/可跑演示/chapters" `
    --terms "samples/可跑演示/术语表_AI大法师.txt" `
    --tables "samples/可跑演示/00_设定表.xlsx" --genre "西幻/异世界"
# 生成"本章注入包"（写手唯一上下文来源，默认精简）
python scripts/build_context.py --chapter 第01章 --tables "samples/可跑演示/00_设定表.xlsx" `
    --genre "西幻/异世界" --terms "samples/可跑演示/术语表_AI大法师.txt" --out "_注入包.md"
# 判据灵敏度/特异度自证（坏稿必命中/好稿必放行/豁免必生效）
python scripts/回归测试/run_regression.py
```
依赖：Python 3.10+（实测 3.12）＋ `openpyxl`；困惑度需 `torch`+`transformers`+本地 Qwen2.5-3B（可选）。

## 四、请重点审什么（6 条）

1. **规则是否过严/过松**：`01_规则书_V0.40.md` 第三节判据（7 门族 ≈78 条），尤其门3 说族占比≤46%、门7 分布上下限（西幻章级档）、门12 跨章事实 C1~C8。
2. **门速查卡是否可执行**：`00_门速查卡.md`——一个新人只看它能否跑通流程。
3. **8 档文风靶板是否靠谱**：`文风靶板_分题材/`——模板是否真能代表该题材；西幻档的"叙述中性＋对白译制腔"是否成立。
4. **样例文本水平**：`samples/01_验腔三段_v2`、`02_中文腔诊断`、`05_作者批注样例`（真人打回点 vs 机器门结果）。
5. **禁词清单的适用范围**：`11_skills包/中文腔禁词清单_v2.json`——作者裁定**仅西幻语域**（武侠/仙侠/历史等对话层不受限），请判断这个边界是否合理。
6. **门精简的取舍**：`17_修复方案/03_门判据精简提案.md` 的思路（本包外，若需要可索取）——哪些判据该删/降级。
