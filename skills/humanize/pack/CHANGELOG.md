## V0.3.2（2026-09-09）

配套规则书：**V0.32**。核心：**把"单章写不长"的根因修掉——加规划表，改单次写足，禁补字**。

### 新增

1. **规划表中间件（阶段1.5，默认路径）**：beat sheet 与正文之间加 60~90 段的任务表（功能/字数预算/状态变更）。
   - 长度由表的字数预算决定（不靠模型自觉）；状态由表钉住（拼稿矛盾在生成时就消失）。
   - 单章目标改 **4,000~5,500 字区间**，不满下限不许停。
   - 默认**方案二**（规划表→单次写足）；备选**方案三**（规划/写作调用分离）；**禁止"写短再补"**。
   - 提示词见 `references/03_提示词包_三阶段.md` 提示词零点五 + 提示词二（打字机模式）。
2. **`references/12_开头技法_真人语料.md`**：13 本真人语料第一章开头实证——**0 本以"某人醒了"起手**；归纳五条共性 + 首句检查表 + 可用句型。
   - 规划表注记（非硬规则）：**首句尽量不用单句**（「XX冻醒了」「XX穿越了」）。
3. **`references/13_提案_语域限定.md`（待讨论）**：西幻叙述层混入北方口语/京味儿/网络梗。
   - 实测：京味儿 21 次 + 北方口语 13 次 + 网络梗 10 次，**东北方言 0 次**——是"北方口语＋儿化＋大陆网络梗"的混搭。
   - 诊断：**叙述者语域失控**（叙述句里用 21 世纪京腔），不是人物吐槽。
   - 提案：语域卡（正面锚）＋ `voice_check.py`（分层机械门：叙述层 0 容忍）＋ 语域对齐替换表。
   - 并解释了"禁止酒馆风"为什么不好使：禁的是短语不是语域；只有负面清单没有正面锚；没有机械门；没有分层。
4. **`references/14_提案_规划表中间件.md`**：五种生成模式的 token 成本对比（方案二 ≈75K/章最省，现行法 ≈95K、分段 ≈98K）+ 六条省 token 操作规则。

### 结论速记

- 单次输出上限不是瓶颈：同一会话内单次写入已达 **12,687 字符**。
- 真正瓶颈：**目标写成"2000字"** + **缺段落级计划** + **事后补字**。

## V0.3.1（2026-09-09）

**由一次外部 AI 审查（43/100「人机协作稿」）驱动的小版本**。核心教训：五道机器门全绿 ≠ 稿件干净——**机器门只查语言层，查不出拼稿矛盾**。

配套规则书：**V0.31**。

### 新增

1. **拼接文段痕迹检查（六条链）**——写进规则书第二节阶段四 + 提示词包提示词四，并独立成 `references/11_恶人编辑_子代理审核包.md`（可直接投喂子代理）。
   - 道具状态链 / 人物动作链 / 时空链 / 说话人链 / 称呼链 / 意象复用链
   - 判据：同一对象短时间出现两个互斥状态＝P0打回
2. **恶人编辑必须独立子代理执行**，禁止生成方自查；环境不支持时必须在报告中显式记录。
3. **章字数极差**判据（门8 观察项）：人类 30%~60%，<15% 报警。
4. 病灶库新增案例 024（拼稿硬伤）、025（章字数齐平）。

### 触发本次修复的实证

一本 10 章新书五门全绿，但外部审查一眼看穿：
- 同一支断弦 20 段内三个互斥状态（扔了→塞腰里→还挂在弓上）
- 同章两次"她站起来"、收纸动作写两遍、"船到河中间/船行到河心"同帧两次
- 同章两次"过了河"，且"走了半天"后突然在原地上马
- **10 章字数极差仅 10.2%**（最强 AI 证据）

根因：逐章补字数时只跑机器门，没做接缝复核。

### 相对 V0.29 阶段的关键变化（已并入本包）

1. **新增门2 `tail_check.py`**——段落尾巴落位核对。根因"模型没有身体"：极短段（≤5字）必须落在 beat 的情绪崩口位，极长段（≥120字）必须落在蓄势位。此前该条款**无任何工具**。

3. **门7 章级配额落地**——明喻引导词按词计数（裸"像"不计，避免"像在念案卷"式误报）、金句癖机器计数、verbatim 需底本禁用短语表。

### 实证记录（本包规则不是拍脑袋来的）

- 用本包复跑一本22章实测稿：**11/22 章尾巴不达标**（9章零极短段）、同构复述3组、说占比60.9%、术语密度16.1/千字。
- 用本包完整写了一本10章新书（19939字）：五门全绿，第3章主钩子/第5章爆点/第6章失败章硬命中，钩子全部悬置。

### 已知限制

- **恶人编辑的独立性依赖外部 agent**：本包只提供协议与提示词，若执行环境无法起独立 agent，只能同会话自查，独立性会打折。
- **AI 审查不可靠**：AI 打分方向性颠倒（三次实证），本包只允许其做特征提名。
- 困惑度需本地模型（Qwen2.5-3B）；`--no-ppl` 可跳过，其余工具纯 CPU。
