  - 其他(14%)：志怪规矩（鬼市索命、炼材倒计时、冥婚）、喜剧误会（圣人认证、装疯捡漏）、穿书法则（作者之笔）、系统规则（孝心判定、签到、悟道积攒）、司法规则（因果镜照恶行+宣判量刑《天牢之主》）、官僚缉查（走私过关《仙界走私大鳄》）、唯物实证（灵气非气体的求真反差《嗟仙》）。
  - 资源争夺(12%)：名额/仙草/灵石/夺宝、分宝博弈、丹方垄断、拍卖行竞价、天降神物归属。
  - 身份落差(10%)：落榜、退婚、弃子、废婿、杂役vs亲传、庶子、质子、炮灰剧本、借尸还魂。
  - 阶层碾压(8%)：杂役制度、仙凡之隔、贱民脱籍、宅斗庶出、魔界贫民区——占比回落，制度压迫让位给情感与规则型冲突。
  - 情感拉扯(11%)（新增主力）：人妖殊途、血契主仆、师徒禁忌、十世情劫、灭族情仇、失恋掳子——女频线把情感冲突做成推进引擎而非调味。
- func 配比规律：铺垫585:悬念371:蓄爽223:压制192:打脸73:兑付48:升级10——前 1 万字铺垫与悬念是打脸的 8 倍；压制(13%)略少于蓄爽(15%)说明「先按住再放」是标准节拍；「升级」几乎不单独成条。
- 可直接套用的冲突链模板：
  1. 抬到最高→当众落榜→独木桥考验→险过入门→羞辱者立 flag 待还（仙逆式憋恨链）。
  2. 机缘被权贵强夺→绝境反悔→当面打脸→金手指觉醒→权贵报复升级（通天仙路式夺机缘链）。
  3. 死局倒计时→金手指缺位自嘲→知识破题→公堂对峙打脸→新谜面（大奉式探案链）；变体：绑定天牢系统→抓恶徒→因果镜曝光→当庭宣判（天牢之主式执法链）。
  4. 灭门/背叛→转世藏拙蛰伏→小场面碾压试剑→逐级清算叛徒网（剑道第一仙/仙绝式复仇链）；变体：掌门残魂附身废躯→以阅历查凶→从最底端翻盘（白狐之歌式暗黑重生链）。
  5. 被弃至尘埃→误吞至宝成众矢之的→大能环伺→宝珠护体→让轻视者仰望（罗浮式弃子反转链）。
  6. 药奴绝境→同伴惨死→搏命吞丹→绝境翻身入仙途（宝塔仙缘式生存链）；变体：误入鬼市→规矩索命→天赋暴露→老道护持→斩妖逐项解锁神通（地煞式志怪链）。
  7. 穿成炮灰→寿命/剧情节点倒计时→拆解原剧情换资源→改命升级→触碰「改不动的人心」（全宗门恋爱脑式穿书链）。
  8. 强者失能错位→被仇人/凡人收养团宠→杀不掉逃不掉→身份谜+深情线并进（仙界多烦恼式错位萌链）。

## 金手指库
- **延迟伏笔型**
  - 机制：来历与规则完全不揭，先给「贴身则暖/微光一闪/纹印入体/事故砸中」。
  - 代表：《求魔》黑色碎片、《凡人修仙传》小瓶后置、《星辰变》流星泪、《超凡传》塔中塔、《踏天无痕》吸血龙鼎、《天刑纪》不出鞘锈剑、《宝塔仙缘》三宝琉璃塔、《光阴之外》愈伤紫水晶、《悟真篇》月华灌体白石床、《叩仙门》雷击金色星芒。
  - 设计要点：只复现不解释；兑现时机=第一个大高潮；此前靠「险过」与心性撑爽感。
- **器灵/伴生型**
  - 机制：老怪物/异宝/灵兽贴身，知识库+护主双功能。
  - 代表：《通天之路》万年器灵、《人道至尊》灯灵薪火、《罗浮》蛑奼珠、《功德印》困于破剑的女魔头、《神宠又给我开挂了》食灵泥鳅、《仙都》灵性青狼、《武仙传》三足神鼎+战魂小龟（吞噬转赠+激将传阵）、《绝色妖仙》人形灵兽双契。
  - 设计要点：给金手指立性格（毒舌/要血喝/要酒/倒计时逼修），人灵互怼即喜剧引擎；须配「本体破损/不能夺舍/元神离体剧痛」级限制。
- **系统/面板型**
  - 机制：经验值、属性面板、数据慧眼、签到、挂机、作死任务量化世界。
  - 代表：《通天仙路》汲取提升面板、《天降我才必有用》看穿双商、《谁在造谣我对她们的孝心变质了》孝心系统、《签到百年》签到系统、《炼气3000层》垂钓系统、《只要把你们都熬死》不死身+年更属性点、《洪荒：证道大罗了金手指才来》悟道系统（十次换顿悟层层递进）、《地府签到千年》千年签到攒神体投胎、《天牢之主》天牢系统（监狱压灵力+因果镜+拘灵具）、《万界修仙交流群》群主权限（跨界收发宝物+大道威压）、《修行，从照顾师娘开始》薪火面板（情缘值换根骨）、《激活培养系统》家族百倍返还+抽奖、《洪荒：开局拍卖鸿蒙紫气》神级兑换系统（本源点直接买境界）。
  - 设计要点：必须配硬限制（能力忽强忽弱、耗体力、权限等级、作死任务、境界永久卡死、惩罚与奖励倒挂），否则数值爽迅速通胀；「迟来型」（证道后系统才来）以资历反差替代数值爽。
- **前世知识/阅历型**
  - 机制：穿越者/重生者的专业知识当武器，含剧情全知与修真阅历变体。
  - 代表：《大奉打更人》刑侦知识、《不朽凡人》开脉药液配方、《地球第一剑》未来记忆、《重生西游》西游剧情全知、《李大开修仙记》现代商业头脑、《嗟仙》理工实证思维（无系统硬靠学识）、《废柴尸解仙》鬼仙道术见识降维碾压凡武、《白狐之歌上》135 年修真阅历（一眼看穿功力深浅）、《我靠摆烂拯救了全宗门》万人迷剧本先知。
  - 设计要点：知识须与本界铁律对撞（凡根世界配开脉药、市井配实证法、虐文配拆恋爱脑）才有独占性；开局宜先「召唤系统失败」完成反套路。
- **境界悖论型**
  - 机制：境界最低、底蕴最深，反差本身即爽点源。
  - 代表：《炼气十万年》十万年炼气、《史上最强炼气期》五千年炼气、《有请小师叔》36 圣道装零修为、《天劫医生》不能修真却能吞雷、《洪荒：证道大罗了金手指才来》大罗之后才发新手礼包。
  - 设计要点：需要一个「为什么卡住/为何成圣」的总悬念托底（十万年不筑基、吞雷体质成因）。
- **硬代价型**
  - 机制：金手指即枷锁，代价驱动剧情。
  - 代表：《功德印》须行善攒德、《天下男修皆炉鼎》作者法则、《这个人仙太过正经》触女昏睡、《恶鬼当道》噬灵虫疗伤后加倍反吸、《武仙传》神鼎吞噬灵气一半+死线反噬、《欲成仙》功力尽封骨中待解。
  - 设计要点：代价要能持续制造荒诞困境与解谜线，而非单纯减爽。
- **体质/命定型**（新增）
  - 机制：特殊体质或天命认证即金手指，宿命感替代升级感。
  - 代表：《恋家癖的神仙生涯》混沌体质（万法触之皆化）、《在仙尊梦里睡懒觉》梦境主宰体质、《小手一挥》铁口神算面相术、《神仙也有江湖》天命石中剑、《我和冥王有个约会》凤舞剑命定认主、《蛇君如墨》饮血结契、《狐王青莲》吞血为主、《连玉》凡躯挡天罚的宿世仙骨。
  - 设计要点：体质须配「被封印/未觉醒/他人不知」的进度条；命定认证宜由权威NPC宣读（拔剑、认主、预言应验）以立信。

## 爽点循环库
- 标准 loop 一（凡人式）：贫贱铺垫→严酷考验→咬牙硬撑→险过获认可→新神秘门槛打开（《凡人修仙传》《大梦主》《宝塔仙缘》）。
- 标准 loop 二（打脸式）：被辱被打压→金手指/心魔赋能突破→当众打脸立威→更大对手逐层放大（《统御万界》《仙侠世界》《至尊神皇》）。
- 标准 loop 三（喜剧/马甲式）：倒霉处境→歪打正着占便宜→喜剧化解冲突→新敌人/新秘密上门（《一念永恒》《渡劫之王》）；变体「苟道误会式」（《我师兄实在太稳健了》《有请小师叔》）；变体「马甲签到式」（《签到百年》《师弟们都是大佬》）。
- 新增 loop 四（穿书改命式）：穿成炮灰/反派→寿命或剧情节点倒计时→拆解原剧情换丹药/机缘→改命升级→撞上「剧情改不动的人心」长线（《全宗门都是恋爱脑》《我靠摆烂拯救了全宗门》《穿书成反派老祖》）。
- 新增 loop 五（错位团宠式）：强者失能变小/变猫/变小道姑→被仇人或凡人当团宠收养→杀不掉逃不掉的错位喜剧→身份谜与深情线同步揭（《仙界多烦恼》《在仙尊梦里睡懒觉》《小手一挥，万鬼臣服》）。
- 爽点类型清单（各配语料实例）：
  - 奇观爽：九龙拉棺空间站失色（《遮天》第 1 章）；神话序章一指开天（《永生》）。
  - 打脸反转：低调亮车不动声色，说教者集体尴尬（《遮天》）；雷术异能越级秒杀御空高手一战立师威（《超级师傅》）。
  - 险中得利：算准雷雨蹲守抢乌龙涎（《求魔》）。
  - 借刀杀人：谎称仇家藏仙草引七八人围杀替己火中取栗（《飞天》）。
  - 智斗借力：喊「有人抢你馒头」唤醒梦游小胖子咬退欺凌者（《我欲封天》）。
  - 捡漏：无人敢要的龟形黑锅恰好被喜欢乌龟的主角抱走（《一念永恒》）。
  - 腹黑反差：当众微笑行礼，转身算计三腿齐折（《嘉佑嬉事》）。
  - 绝地反杀：决斗濒败催动闭息术一剑破面掀翻巨汉（《魔天记》）。
  - 强者降临：黑伞独闯冥婚一句「人来的挺多」满场凝滞（《真实世界》）。
  - 时间差复仇：被打不吵不闹，专等仇家老去（《开局长生万古》）；不死身苟到「衰老骑脸」地头蛇碾压（《只要把你们都熬死，我就能无敌》）。
  - 经营走私爽（新增）：废柴劫仙偷渡人界电器上仙界倒卖，小生意滚成商业帝国（《仙界走私大鳄》）。
  - 群聊装大佬爽（新增）：天降手机建万界修仙群，打工仔冒充道主骗宝自肥（《万界修仙交流群》）。
  - 执法宣判爽（新增）：「你现在有权利保持沉默……天牢之主，陈然！」当庭拘灵收押（《天牢之主》）。
  - 唯物求真爽（新增）：「灵气居然不是气体！！！」实证思维破解修仙界公理（《嗟仙》）。
  - 错位萌爽（新增）：妖尊法力尽失变猫，撞上灭族仇人杀不了反被撸（《仙界多烦恼》）；废柴少女在魔气封印地安睡，仙门全员供成救命稻草（《在仙尊梦里睡懒觉》）。

## 剧情走向参考
- 前期推进路径①入门爬阶流：入门考验→杂役/记名立足→外门→内门→大比夺名；每一级配资源分配制度，爬阶即冲突。代表：《真灵九变》《凡人修仙传》《宝塔仙缘》《混沌雷修》。
- 前期推进路径②绝地求生流：凶岛/废土/绝杀大阵内人人相残，夺宝—结盟—背叛—出地图。代表：《魔天记》《光阴之外》《飞天》《无极魔道》。
- 前期推进路径③归乡清算流：强者/重生者归返，先写最暖再验伤，一夜端巢；中景反派是盘踞数十年的窝案。代表：《飞剑问道》《前任无双》《朝仙道》《仙榜》。
- 前期推进路径④市井搞钱流：以经营、算计与信息差攒第一桶金，仙缘从生意场里长出来。代表：《李大开修仙记》《通天之路》《罗喉》《仙路至尊》；新增变体：跨界面走私与拍卖经营（《仙界走私大鳄》《洪荒：开局拍卖鸿蒙紫气》）、家族经营滚雪球（《激活培养系统，打造无敌家族》《半步人间》九方灵田）。
- 前期推进路径⑤探案平事流：每章一个案件级悬念+一次兑现，「接案—查访—破题—结案」的单元剧结构串起大阴谋。代表：《大奉打更人》《真实世界》《天刑纪》《过河卒》；新增变体：建监狱抓恶徒的执法单元剧（《天牢之主》）。
- 前期推进路径⑥苟道长生流：以年/十年为刻度攒复利（属性、签到、功法），冲突来自「被看见」，大时代变迁做远景压力。代表：《开局长生万古苟到天荒地老》《签到百年》《只要把你们都熬死，我就能无敌》《洪荒：证道大罗了金手指才来》。
- 前期推进路径⑦情缘历劫流（新增）：贬凡历劫、转世虐恋、人妖殊途、血契宿命——以情劫为推进引擎，前世今生双线并进，障碍（仙规/殊途/倒计时）逐段收紧。代表：《人间微醉》《折兰勾玉杏向晚》《连玉》《醉狂》《狐王青莲》《前缘》。
- 长线动机设计套路：
  - 复仇清算：叛徒网逐级揭，清算对象从近敌到幕后（《剑道第一仙》《仙绝》《仙榜》）；新增变体：五岁立血誓的光暗双修复仇（《天纵妖娆》）。

  - 改命长生：凡根、寿元将尽、绝脉，以制度性绝境驱动（《凡人修仙传》《大梦主》《一念永恒》）。
  - 履约型：九个约定的玉镯、修到长生境应两个条件（《天渊》《玄衍神术》）——以承诺制造不可回避的行程表。
  - 时间复利型：等仇家老去、签满百年（《开局长生万古》《签到百年》）——以时间本身为资产。
  - 归家执念型（新增）：为再见爹娘执着成仙、在牢笼谜局里攒一个家（《仙有仙归》《恋家癖的神仙生涯》）——以「家」为动机锚的治愈向长线。

  - 高分做法：双动机并联（救亲线+仙界复仇线《朝仙道》），情感线供温度、复仇线供推进。
- 悬念管理：
