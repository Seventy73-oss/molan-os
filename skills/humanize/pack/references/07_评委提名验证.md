# 反向skills · LLM评委提名验证工作流

> 何时读：**做 AI 提名 / 设计盲评时**｜适用题材档：**全题材**


> 状态：第一组循环收官正式启用（此前暂存）。
> 依据：盲评01~03 三轮的人机评委对照数据。LLM评委打分不可用（方向性颠倒已三次实证），但其**特征提名**在验证后持续产出有效规则。

## 一、已实证的评委失效模式（反向使用的依据）

1. **方向颠倒**：小模型给真人段的分高于AI段（盲评01模型B/C、盲评03旧B）——总分永远不可用。
2. **瑕疵反指**：把真人错别字/半角标点当"AI未校对证据"（旧B，盲评03）——瑕疵是真人信号，不是AI信号。
3. **基率忽视**：把真人网文常见的解说排比、清单节奏、数字工整当AI铁证——特征真实≠定罪，要问基率。
4. **误报人格化**：评委被"反逻辑冷幽默"说服为真人（对），也会被"工整合理"说服为AI（错）——它检验的是文风质量，不是作者身份。

## 二、工作流：提名 → 验证 → 入库

```
1. 提名：让大参数评委（≥上一轮最佳水平）对混评材料点名
   "指出疑似AI段落，并给出具体句子+特征名。禁止输出总分。"
2. 去偏约束（评委prompt必加）：
   - 瑕疵（错字/半角标点/主语混乱）不得作为AI证据；
   - 清单节奏、数字工整、解说排比在真人网文高频出现，单独出现不得定罪；
   - 只允许输出：段号 + 具体句子 + 特征名。
3. 验证：作者金标准比对——该特征在作者打0分的段里出现过→驳回；
   在作者高分段里出现→入候选池；
   候选特征做密度统计（真人语料 p90/p95 定阈值），超阈值才升为规则。
4. 入库：新规则写入 deai-rules 修订层，标注提名模型与验证轮次。
```

## 四、评委选型结论

- 大参数模型（盲评03的"大参数B"）：三轮唯一同时抓出全部裸写段+点中规则段的评委，**唯一保留的提名器**。
- 小参数模型：方向颠倒概率高，弃用。
- 评委的"理由文本"永远比"分数"值钱；分数仅存档不使用。

## 五、第二组循环补充（作者指示，2026-09-07）

1. **04-2 协议修正**：整章测试改为"同一位置成对对比"——AI 续写上一章得到的整章 vs 原作者的真章，两份一起给出。这样才能对齐"同一故事位置"的文风差异，排除选题/情节差异干扰。
2. **AI 评委缓存问题（重要）**：LLM 评委普遍在训练数据里见过热门网文，对真人原章有记忆，评分天然失效，且与测试间隔时间无关（缓存不是时间能搞定的）。结论：
   - 整章级测试（04系列）的 AI 提名器作用有限，权重下调；
   - 若必须用 AI 提名，选底本冷门化（新书/小众书/未公开文本），或对真人章做轻微扰动后再给评委；
   - 切段级测试（01/02/03系列）受缓存影响较小，AI 提名仍可用，但仅供参考。
3. 第二组循环顺序：盲评01-2（切段改写）→ 02-2（切段续写）→ 03-2（混合条件切段）→ 04-2（整章成对对比）。
