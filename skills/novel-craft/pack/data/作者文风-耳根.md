# 耳根 文风档案（6 本仙侠蒸馏）

> 语料来源：《一念永恒》《光阴之外》《仙逆》《我欲封天》《求魔》《三寸人间》style 七维逐本原文 + anchors 金句。
> 耳根是书库中仙侠文风最一致的多本作者——六本书横跨欢脱喜剧到苍凉史诗，但底层指纹高度稳定。

## 风格核心

1. **落差造主**：耳根的主角永远从"被抬到最高处摔进冰窟"或"最底层杂役/废土孤儿"起步，先用世态炎凉把主角摁到尘埃里，再让他在尘埃里憋出一股不肯认命的执念——求道感不是喊出来的，是被羞辱和绝境"压"出来的。
2. **双声道写法**：苍凉与谐趣在耳根笔下从不单行——《一念永恒》欢脱外壳藏"我要长生"的热流，《三寸人间》沙雕官场心机埋热血野心，《求魔》篝火欢笑紧邻割首血祭。喜剧是糖衣，孤独和宿命才是馅。
3. **金句宣言收束**：耳根的关键节点必放"单句成段的宣言炮"——"我若要有，天不可无"、"从此我苏铭就是魔"、"举头三尺无神明，掌心三寸是人间"，用一句掷地有声的话替主角完成身份与道心的自证。

## 跨书一致性

六本不变的个人签名（指纹级）：

- **开局公式**：底层/受辱/绝境起步 + 一个"信物/金手指"引路 + 立刻进入组织（宗门/联邦/部落）。凡《仙逆》全村希望当众落榜、《我欲封天》三连落榜被掳、《一念永恒》全村演戏送怂小孩、《求魔》部落"不太一样"的少年、《光阴之外》禁区孤儿、《三寸人间》心机胖子靠面具作弊，全部如此。
- **世态炎凉对照法**：村人前后恭维、族亲当年逼父如今道喜（《仙逆》）；送别的假煽情与真欢呼（《一念永恒》）。人情冷暖是耳根写"道"的第一块基石。
- **反派耳语立 flag，预写打脸**："傻小子，你不会被选中的"——《仙逆》开头就埋好收网时刻。
- **心理独白吐槽消化压迫**：仙凡落差全用主角算账式内心戏化解（"给仙人打工""百金工钱"，《我欲封天》），压力越大吐槽越密。
- **意象重复埋钩**：碎片微光"一闪而逝"两次复现、埙曲之悲（《求魔》）；神灵残面、血雨结界（《光阴之外》）。
- **单句成段放炮**："不合格。"三连（《仙逆》）、"雪，更大了。"（《求魔》）——关键转折永远用最短的句子砸。
- **环境开场 + 意象收束**：大青山落日扔葫芦、理想随河水漂远（《我欲封天》）；喀喇骨卜声先于画面入耳（《求魔》）。

## 视角与人称

- **基础配置**：第三人称限制视角紧贴主角——单视角贴许青（《光阴之外》）、贴孟浩（《我欲封天》）、贴苏铭（《求魔》）、贴王林（《仙逆》）、随王宝乐（《三寸人间》）。耳根几乎不脱离主角看世界。
- **全知的两种偷用**：一是"临时代入外部视角"围观吐槽主角——乡亲、李青候、麻脸女子（《一念永恒》），章末切老师群像制造双重反差（《三寸人间》）；二是短暂插叙旁人内心补势利底色——王卓之父"心道老四这次把名额让出"（《仙逆》）。
- **无人称电影镜头**：史诗段落切换为纯镜头——魔序段（《求魔》）、神灵睁眼屠城（《光阴之外》），先给大场面再下探到具体的人。
- 贴身视角的代价与收益：信息靠主角的求生缝隙"层层展开"（《光阴之外》），读者与主角同步无知、同步顿悟。

## 句式与节奏

- **短句主导是铁律**：《一念永恒》短句主导、中句衔接、长句极少；《我欲封天》短句四到十二字；《光阴之外》"一句一段的断行节奏，画面感与呼吸感强"；《仙逆》"一段一节拍，翻页极快"。苍凉感正是靠断行实现——句子越短，天地越空。
- **长句只做两件事**：开篇写景铺气势（"风掠过了北漠羌笛，吹过了东土大唐"，《我欲封天》）；序章排比渲染史诗感（"一层层洒满大地，远远一望，若银装素裹"，《求魔》）。正文推进时长句退场。
- **碎句推戏**："白小纯愣了一下"式动作碎句是耳根的过场粘合剂，动作与对白节奏极快。
- **长短交错如说书**：叙述段长短交替，但笑点句、转折句必须独立成段。

## "求道"写法

耳根的"道"从不在文字上说教，全部落在情节机制上：

1. **道 = 一个具体的执念**，且必须口语化说出来："修仙不是能长生么，我想长生啊"（《一念永恒》）——求道的第一步是把欲望说得像人话。
2. **道 = 对世俗规则的一次反叛宣言**：世人要他当仙，他偏成魔——"既然世人皆称我为魔，则索性，从此我苏铭……就是魔！"（《求魔》）；"我若要有，天不可无；我若要无，天不许有！"（《我欲封天》）。宣言句永远出现在被逼到墙角后。
3. **道 = 把宏大换算成生存账**："与其去担心未来异化，不如去担心明天是否还活着"（《光阴之外》）——耳根把"求道"降维成"求活"，再在求活中让道心自然长出来。
4. **道 = 苦修循环的反复兑现**：砍柴苦修 + 小聪明反击完成首个翻身（《我欲封天》），三天生死毅力考（《仙逆》），夺宝修行苟活翻身循环（《光阴之外》）——道心是靠一次次小翻身"攒"出来的，不是顿悟出来的。
5. **道的排比式自白**：用庄严句式做错位宣言制造双重效果——"我王宝乐是一个高尚的人，一个正直的人……"（《三寸人间》），既是笑点也是野心。

## 情感基调

六本书的基调配比是一个连续光谱，但切换手法同源：

- **先暖后冷 / 以暖衬冷**：人间烟火的荣耀与亲情托底，筛选的冰冷现实收网（《仙逆》）；篝火越暖，"殇"的影子越近（《求魔》）——温情段落永远为下一记重锤蓄力。
- **苦中带暖的谐趣**：底层辛酸被乐观性格软化，暗藏森冷（《我欲封天》）；欢脱戏谑之下藏执念热流（《一念永恒》）。
- **压抑孤绝 + 倔强求生欲**：这是《光阴之外》的底色，也是所有耳根主角的隐藏底色——只要活着，其他就不算什么。
- **热血压轴**：轻松沙雕外壳下埋热血与向上野心（《三寸人间》）。
- 配比规律：喜剧浓度与苍凉浓度成反比，但两者必同书共存；孤独感是所有六本的公约数。

## 对白写法

- **占比梯度大**：45%（仙逆）→ 45%（一念永恒）→ 40%（我欲封天）→ 30%（三寸人间）→ 25%（求魔）→ 极少（光阴之外）。耳根按题材调对白阀值：市井喜剧高对白，苍凉史诗用独白与环境描写承载信息。
- **对白即人设**：李青候问"为什么点了三年"的捧哏逗哏结构；胖子群口喜剧输出宗门生态（《一念永恒》）——每个人物开口三句立住性格。
- **功能三分法**（《我欲封天》）：规则交代（马脸青年）、世界观带出（绿袍人闲谈凝气七层）、喜剧调剂（小胖子哭嚎"我亲事都说完了"）。每段对白必须至少干一件事。
- **群像台词替代旁白**：村人欢呼交代替世界观（《一念永恒》），族人喊"拉苏"的寒暄承担温度（《求魔》）。
- **反派台词专司立 flag 蓄恨**——反派开口即是在给读者预支一场打脸。

## 用词底色

- **口语底色 + 温热说书腔**：市井气浓、评书腔点睛（"一肚子坏水"），整体通俗，成语偶用（《仙逆》）。
- **分层切换**：《求魔》书面化、苍茫古拙、史诗咏叹腔、悲悯底色；《光阴之外》冷冽诗化（墨色血雨、残面、孤狼）；《三寸人间》庄严词汇错位使用制造喜感。耳根能在一套语法内换三种"漆"。
- **诨名连发**：白鼠狼、白九胖、肉山（《一念永恒》）——配角一律外号化，读者零成本记忆。
- **主角内心吐槽是主调味剂**："给仙人打工""百金工钱"（仙凡落差用算账消化），无中二口号。
- **意象库**：孤狼、残面、血雨、篝火、落日、葫芦、河水——自然物象承担情绪，不直接写心情。

## 创作参考：怎么写出"耳根味"

1. **开局三章定理**：第 1 章把主角抬到最风光处（全村希望/欢送仪式），当众摔进冰窟（落榜/羞辱/灭村），第 2-3 章给一根独木桥（信物、金手指、组织入场）——落差幅度决定后续热血存量。
2. **每章一个"单句成段"的炮**：转折、宣言、判词用最短句独立成段（"不合格。"、"雪，更大了。"），一章至多两枚，放多了哑火。
3. **对白按题材定阀**：市井轻松向对白给到四成、人设全靠对话立；史诗苍凉向压到两成半以下，信息改由独白与环境描写承载。
4. **压力换算成吐槽**：主角遭遇任何压迫，先写一段"算账式内心戏"把宏大处境翻译成市侩账目（"给仙人打工"），再写反击——吐槽密度与压迫强度成正比。
5. **以暖衬冷的节拍**：温情段落（篝火/家庭絮语/村人欢呼）之后必须紧跟一记冷收网（血祭/筛选/离别），不许温情段落连续出现两次。
6. **配角一律诨名化 + 功能三选一**：每个有台词的配角要么扛笑点（肉山、小胖子），要么扛设定（绿袍人闲谈），要么立 flag（反派耳语）——三者不兼任。
7. **意象重复埋钩**：核心意象（微光、埙曲、残面）至少出现两次，第二次出现时才引爆其含义；开篇写景用长句排比铺气势，之后立刻切回短句。
8. **道心宣言三步走**：先口语化说欲望（"我想长生"）→ 被逼到墙角 → 单句宣言自证身份（"从此我就是魔"）——宣言必须在绝境之后，不许提前。
